## Evidence
Frame: the 0x18 vs 0x10 difference is the saved s-register count (s0-s3 at 8-0x14 vs s0-s1); sp+0..7 is unused in both. A pad local does not restore it: the command variable in $a2 is what pushes the constants into s registers.
Colouring is bit-order (all "assigned (unconstrained)"): the register a candidate gets depends only on which earlier-bit candidates it interferes with. On the old op-copy body (before 2026-11-17), op had to appear before w0 (the guard order is irrelevant: params a0/a1 take bits 0/2 and their own registers), and command had to stay a stored variable to the loop end for the ushr web to overlap the mask web (mask forbidden $v0 -> $a3).
Copy phantom (2026-11-17): a local assigned from an already-CSE'd load (`w0 = cmdStart->words.w0` after `command = cmdStart->words.w0 >> 24`) is a candidate live from bb2 to bb4 at colouring time and takes a register ($a2). After colouring, its reads are served from the load's register ($v1: `nor t6,v1,zero` at 0x270), so the copy emits no code. This is what the target's empty $a2 is. The working copy assigned first (`clear = swapped = ...`) colours swapped ($v0) before clear ($v1); the clear mask then avoids v0/v1/a2 and takes $a3 (0x278).
