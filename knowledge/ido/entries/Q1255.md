File src/arcade/0.c, arcadeDrawStage3Background e89353 (was 1489cd). Extends Q0811, Q0780: with the bound in a local (`n = sizeof(t) / sizeof(t[0])` or `n = 21`) and a pointer walk `pt < t + n`, uopt builds the end from the walker register (`addiu s1,s0,0x54` at 0x3884) instead of folding it to `%lo(t+0x54)`, so no `(s32)` round trip is needed. An index loop `i < n` is still end-pointer rewritten (sltu on pointers, end in s2): the local does not block LFTR as Q0780 says. `s32 n = ...` as a declaration initialiser moves the store to entry (69). AMEND Q0780: its "director-accepted as natural" note is overruled (2026-11-17f): a constant-valued count local whose position steers keeps `// FAKE` (SKILL §5.6, Q0816).
