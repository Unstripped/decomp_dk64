In race/6650 raceSteerTowardTargetWaypoint the target reloads D_807FDCA0 after each call and recomputes `&entries[idx]` from the spilled idx. A pointer local taken before the calls keeps the address in a callee-saved register instead, so the source indexes the global at each use.
