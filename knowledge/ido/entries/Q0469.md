order is adjsave, ties by candidate number, first-fit lowest free register; each extra statement referencing a variable adds about +1.0 adjsave, while dead tests, `x = x;` and `x += 0;` vanish before allocation. An early dead test of a global merges its later loads into one CSE candidate spanning the region (v1 forbidden there pushes it to v0). `G1 != G2` gets `beql G1,G2` only when `G2` is loaded first. A defined loop variable with a long live range (`k = 0;` before, `if (k != 0) {}` after) reorders colouring. Dead tests on pointer field expressions (`if (p->q->f) {}`) steer FP colouring where locals do not.
