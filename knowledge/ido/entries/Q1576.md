C0EE0 enemyGridStateStep: the empty `default: break;` owns the block 0xa58 (`lw a3,0(t2)`, the gCurrentActor reload every case path makes) that falls into the join 0xa5c; case blocks end `lw a3,0(t2); b a60; lw v1,96(a3)` because the join's first instruction fills their delay slot, so they appear to target 0xa60. The bound check (0xc4) and gap entry 5 go to 0xa58. The explicit default also gives the explicit empty `case 10: break;` its own block (0x970). Removing the default sends case 10, the bound check and the gap entry to the join and shrinks .text 3984 -> 3824; moving the default changes only relocations; `case 10: default:` shares one block (-12 bytes).
