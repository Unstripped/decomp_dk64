`for (;;) { body; if (p == end) break; }` suppresses the unroller, `do { ... } while (p != end)` unrolls 4x/8x with a `divu` remainder preheader; a counted `for (i = 0; i < 8; i++)` over a struct array becomes 2 iterations of 4 compares (`mapSearchTableGetValue`).
