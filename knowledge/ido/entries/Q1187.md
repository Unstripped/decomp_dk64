In C0EE0 enemyGridStateStep, `if (ones == 0) {}` (dx < -1 clamp block) and `if (cell & 3) {}` (dy < -1 block) each worked only by reading their own value (Q0908 availability class: a guard on `1` scored as removal, 7 and 94). Merged into one `if (ones == 0 && col) {}` (col = cell & 3, the same value) the function matches with the guard inside any of the four clamp blocks; before/between them it scores 67, after the gridX/gridY writes 7. Operand order matters (`col && ones == 0` 4); `ones == 0 || col` 67; nested ifs also match. Two availability-class dead tests in one region are worth trying as one two-term guard (one FAKE fewer).
