Rewriting `i = 0; do {...} while (i < N)` as `for (i = 0; i < N; i++)` adds a block (the entry test) to the ranges live across it, lowering a constant's adjsave without code change elsewhere; so loop form is a natural priority lever. Block units are not additive with dead ifs: the divisor moves in steps (Q0523).

Evidence: controllerUpdate (global/F600.c), case 2: the `for` form took const 2's adjsave 8.385 -> 7.786; one dead if alongside the `for` changes nothing, two do.
