from `alHeapInit` (`0x80732420`) on, code has every argument homed, a dead `b` to the epilogue after each `return`, and two `jr $ra` at the end of void leaves: unoptimised `-g`. IDO 5.3 `-g` reproduces the statement shapes but never the in-place forms 7.1's ugen emits (`sll s0,v0,16; sra s0,s0,16` for an `s16` call result passed as an argument, `srl a0,a0,1; andi a0,a0,0xff` on a `u8` param, `move at,a0; sll a0,at,2; subu a0,a0,at` multiplies); 7.1 matched all of them unchanged. Makefile `GLOBAL_G_FILES` selects `/opt/ido7.1/cc` and `-g` per file.
