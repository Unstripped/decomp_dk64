converting an unsigned narrow value still emits the u32 `bgez` + `2^32` fix-up; storing an `f32` into `u8`/`u16` emits the unsigned `cfc1`/`ctc1` cluster unless cast `(s32)` first (then plain `trunc.w.s`). A `(f32)(u32)` cast on a u8 array element compiles the same as using the element directly in an f32 context, so the cast can go (`bossMainStep`, F0D0).
