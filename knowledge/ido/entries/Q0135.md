converting an unsigned narrow value still emits the u32 `bgez` + `2^32` fix-up; storing an `f32` into `u8`/`u16` emits the unsigned `cfc1`/`ctc1` cluster unless cast `(s32)` first (then plain `trunc.w.s`). A `(f32)(u32)` cast on a u8 array element compiles the same as using the element directly in an f32 context, so the cast can go (`bossMainStep`, F0D0). More no-op casts: `(u32)` on u8 globals in double arithmetic and `(u8)(u32)f` on an f32 -> u8 store (7 casts in `sfxUpdateLevelAmbient`, 7130); `(u32)` on f32 -> u16 field stores and `(s32)` on f32 -> s8 field stores (5 casts in `bonusActorUpdateVertexPositions`, 2690).
