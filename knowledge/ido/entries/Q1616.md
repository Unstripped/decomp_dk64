478F0 csCmdSpawnScaledSphereEffects: `for (i = 1; i < n; i++) { vec[1] = i * 0x2A8; ... }` gives exactly the old source's hand-rotated loop: guard `slti n,2`, exit test `i != n`, strength-reduced 0x2A8 induction. A hand-rotated `off += K` loop with an `n >= 2` guard can go back to a plain `for`.
