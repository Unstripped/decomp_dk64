When the target keeps a value in a reused local's callee-saved register and narrows it at the argument (sll/sra) as for that local, a dedicated local is its own short web and loads straight into the argument register without narrowing (a2; v0 for s32). Evidence (hudPauseMenuRender cfa137): count in s3 at 0x1c64, `sll a2,s3,0x10` at 0x1c74; a dedicated count gives `lh a2,66(a2)` at all 25 declaration positions. Register sharing alone does not make the reuse original source (it stays a tagged steer).
