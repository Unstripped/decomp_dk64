Refines Q1558/Q1589/Q1591: `spilltemps` hands out spill-temp slots in candidate-bit order. For a value that is never coloured (adjsave < 0), only an earlier appearance of the same candidate in the ucode moves its slot; extra CFG nodes (one-case or inner switches, goto/label, empty switch) and dead initialisers do not. effectSpriteRenderPool (global/114270.c) 2a0256: with the guard `ucvt(count)` is bit 37 (adjsave -6.0, slot 0x64); without it bit 125 behind bits 111/115 (15.0) and the slot drops to 0x5c, under every node variant.

Narrows Q0570: `switch (x) { case 0: break; }` creates the same `ucvt(x)` candidate at the same bit as `if (x == 0) {}`; an empty `switch (x) {}` creates none. The one-case switch is ordinary C only where sibling code really switches on x.
