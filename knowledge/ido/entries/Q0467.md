every declared scalar takes a 4-byte slot in declaration order (highest first), block-scoped ones too; pads only count before a referenced array; arrays are 8-aligned (one extra scalar below costs 8); adjacent `u8` locals pack; memory-resident variables appear in ascending address order (declare in reverse); a 1-element array local stays memory-resident (`sw` at def, `lw` per use) while `&var` taken into a pointer does not keep a scalar in memory; constant-indexed f32 arrays stay in memory; in a leaf, f64 locals get no slot unless spilled. `x op= f()` makes cfe add a hidden call-result temp word; taking the result through an existing local avoids it. Scoping call-result locals inside their block moved a temp spill slot with the same frame. Temp spill slots are first-come 8-byte slots.
