tile loops use a single `i` with `i * 0x20 + K` arguments (IDO strength-reduces the coordinate; a separate `x += 0x20` costs saved regs and frame); `x += 0x20` limits become `bne` with the limit in a register unless the step is a variable; `for (p = START; ; ) { ...; p++; if (p == end) break; }` with `end` a local prevents unrolling; `for (i = 0; i != N; i += step)` puts the increment after the body's calls.
