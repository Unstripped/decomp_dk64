Index a global array directly (`D_807F6C18[i].f`), and declare a symbol indexed as `((s8 *)&D)[i]` as an array, or uopt never builds the stride-1 induction pointer. An odd `lw v0; lbu t,..(v0)` in the target is a named pointer local (named locals are uopt candidates; chained expressions are ugen scratch temps): 302 → 0 lines.
