When temps carry several unrelated roles and the frame has no spare word, a dead guard may be serving a value that should have had its own local. Rewrite one temp's roles out first to free a correctly placed slot, then give the guarded value its own local.

Evidence: vehicleUpdateMotion (global/936B0.c): `if (tiltRoll && tiltRoll) {}` was a same-value class (guards on 1 or other locals 55, `if (tiltRoll)` 44, only the double use 0), needed only because the turn factor shared tiltRoll. Respelling tmpA's three unrelated roles (an inline ternary divisor, field reads) freed slot 0x5c for an `s32 turnScale`; the guard went with fdiff 0 and the frame unchanged.
