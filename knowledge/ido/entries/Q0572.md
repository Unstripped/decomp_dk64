In IDO 5.3, an embedded assignment in a condition like 'if (entry->unkC == 0 || entry->unkC == (two = 2))' artificially forces constant 2 into a register operand (s6) for a bnel instruction. Introducing a clean named local 'kind = entry->unkC; if (kind == 0 || kind == 2)' matches the identical code generation and register allocation cleanly without the assignment hack.
