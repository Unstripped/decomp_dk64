`u8 flag = a && b;` makes cfe evaluate into a frontend int temp (homed below every named and macro-block local, here `0x60`); when uopt copy-propagates `flag := temp`, later uses read `(u8)temp` as `lbu 0x63`. Any later `?:` in the function reuses the same frontend temp and blocks the propagation (the `u8` home then shows up as `sb`); writing the selection as `if (flag) dl = a; else dl = b;` into a named local reproduced it (`mapChunksRender`, 884 insns, ROM-verified).
