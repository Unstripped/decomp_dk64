Extends Q0953/Q0591. Case labels placed inside a statement compile like the goto they replace: a backward goto equals `for (;;) { tail; break; case N: ... }` (same `b tail+4` with the tail's first instruction in the delay slot: bonus/0 bonusControllerUpdate uef380, `b 0x2f8` at 0x35c); two forward gotos equal one `do { ... break; ... } while (0)` holding the case labels; a forward goto from a case into the default arm after its first statement equals `if (0) { default: X; }` (global/201B0 camComputeEyeFocus u71b9c, 0x926c -> 0x92c4). All full=0. These forms are still steers: a matching Duff form is no evidence against keeping the goto.
