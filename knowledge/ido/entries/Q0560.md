`modelAnimEntryBuildKeyMatrix` (leftovers revisit 13, matched with no FAKEs after 17 attempts): (1) ugen's FP scratch ring is a FIFO like the integer one (Q0554); each allocation takes the head. `0.125 * n` emits `li.d` first so the constant takes $f10, while `(f32)((n) * 0.125)` emits `cvt.d.w` first, giving ring order f10, f6, f8, f4; the wrong order showed as every switch case's ring names rotated by two (`mtc1` on $f6 instead of $f10). `.scratch/R13_sonnet_xhigh_9/fpfifo.py` models it with zero mismatches. (2) All webs of one variable share a colour, so interpolation chains that share `fa`/`fb` force one register across regions; giving each chain its own pair (`fc = next; fd = cur; cK = (fc - fd) * arg1 + fd;`) took masked shape 29 -> 8. (3) `v *= expr` never copy-propagates (`no_nested_ops`, Q0559); writing the case as `c2 = ((fc - fd) * arg1 + fd) * k;` (recomputing the dominating assignment's expression) let uopt keep that value in a temp register from the dispatch node through the case and leave c2 uncoloured, reproducing the target's delay-slot `swc1 $f2,216(sp)` and the later `lw a3,216(sp)`. The function also needed a real `f32` parameter (ANSI prototype, Q0556 paragraph) and `f32 unk4` in `ModelAnimEntryRaw`.
