(uopt cse-hoist/regalloc; related Q1012, Q0908, Q1031, Q0556) A stored value is not forwarded into a re-read of the same field when the stored expression reads that field: after `p->f = g(-p->f, ...)`, a following `if (p->f != 0)` in the same block keeps a fresh ilod in its own register (as1 turns it into `move a3,t8`), and the stored value stays a ugen temp. So writing the field read instead of a local that held it removes a position-locked block-split guard (+0x34C negu a0,a3; +0x3F0 sw t8,16(v0); +0x418 move a3,t8; no label between store and read in the uopt ucode). 2. (uopt regalloc; related Q1033, Q1012) A single-test local `x = y + 1` stays a register variable only if y changes between its assignment and the test. Otherwise uopt substitutes the expression into the test, giving a folded test or a ugen temp.
