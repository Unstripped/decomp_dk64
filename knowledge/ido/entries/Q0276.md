`if (c) {...} else { }` (explicit empty else) gives the then-block's `b .Lx` with a filled delay slot; a `switch` whose last case ends in `break;` needs `default: break;` for the extra `b; nop`; one `case` + `default` gives `bne; b; nop`; a path that must branch to the common end needs its own `break;` rather than an `else` (`__n_CSPHandleMIDIMsg` case 0x90). fdiff's label-normalised objdump hid that wrong branch target; only the ROM gate caught it.
