EXTENDS Q0781 and the element-read entries (related Q0900, Q0175, Q0776): when one function reads the same `a[i]` element in two separate blocks, the second block's address register depends on both blocks using the same spelling (one shared pointer local, or element reads in both). Mixing an element read in one block with a pointer sum or an `&a[i]` local in the other moves the second address to a different register (0x3d04 goes to v0 instead of v1 for every mixed pair tested). Fixing only one site can therefore look like a miss.
