2F550: a hand loop `for (;;) { if (node == NULL) break|return; ...; node = node->child1; }` compiles byte-identically to `if (node == NULL) return; ...; f(node->child0); f(node->child1);` (the second, tail call becomes the loop). `while (node != NULL)` is rotated (16 bytes shorter) and fails. In mapTreeResolveNodeAssets the recursion holds with a break-only switch and no `default`.
