Natural constructs that add uopt blocks can replace dead-test priority steers (Q0523): a one-case `switch (sel) { case K: ... break; }` on a dispatch selector, and MAX/MIN `?:` macros in a min/max scan, change the adjsave of the address/end/limit webs the same way. LIMIT: use the one-case switch only where a single-case dispatch on a selector (an opcode, a kind/state byte) reads naturally, never as a block-boundary device on an arbitrary condition.

Evidence: frameTimingUpdate (global/5230.c, max/min scan) and mapChunkLoadAssetRefs/mapChunkReleaseAssets (global/55B20.c, `switch (opcode) { case 0xFD: ... break; }`, f02d949d) replaced 3 dead tests; projectileSpriteRingUpdate (global/9BF30.c, c17942, cae67074), cf. race/0.
