playerStateLandRecover (D5E10) reused `f32 f` for the ledge/floor height deltas and the case-0 animation frame; every split grows the frame 0x50 -> 0x58 (homes +8) at every position. The census's no-local test found the fix: reading `gCurrentActor->sub4->model->frame` directly at each compare (case 4/5 three reads, case 6/7 two, as case 2 and default already did) lets uopt merge the reads into the target's $f2 loads (0xd2c4 with its reload 0xd31c after the call, 0xd3c8/0xd420, 0xd584): fdiff 0, no local for the frame role, FAKE removed; `f` became `heightDelta` (one role: the absolute height gap tested against the 20.0 fall threshold). Q1612 lists playerStateLandRecover as a reuse every split breaks; that no longer holds (its playerStateSurfaceTreadWater case still does: a frame-keeping split changes only $f14 -> $f0, R5).
