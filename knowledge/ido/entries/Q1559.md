8F4B0 lightUpdateFromActorLighting: `if (x) { break; case N: ... }` then the shared code turns the break into the fall-through
`b end` (the branch skips the then-arm): `beqzl t2,0x150` + `b 0x238` at 0x12c-0x138 (5 lines) vs the target's `bnez t2,0x238` +
`b 0x150`. Only `if (!x) {} else { break; case N: ... }` (a steer) restores the order; the goto stays (Q0591).
