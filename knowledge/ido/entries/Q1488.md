Extends Q1470 (a TU's .bss is ordered by symbol number mod 256; see also Q0565, Q0761, Q0981). A function-local static is numbered in the same sequence as file-scope objects, and its landing window can be one slot wide: in global/7130.c only N = 160 (mod 256) dummy definitions put the static D_80770DC8 at .bss+0x868; 159 and 161 miss.

What is numbered:
- data and tentative definitions: 1 each;
- function definitions: 2 for a two-parameter function (10 empty `(void)` functions took 29+);
- the first use of an extern: about 1;
- string literals: about 1;
- a block-scope static: 1.

Not numbered: typedefs, enums, struct members, prototypes, unused externs, local autos, float literals.

Declaring .bss objects `extern` at the top and defining them later numbers them at their first use, which breaks address order.

Evidence: global/7130.c sfxUpdateLevelAmbient (unit CleansfxUpdateLevelAmbientc, merge ec3c9426).
