HackbonusTargetGameUpdate (unit "2026-11-16c: cleanup HackbonusTargetGameUpdate", merge 0a7cfd1f), src/bonus/2690.c bonusTurtleTroubleSnakeUpdate (uopt/ugen): what looks like a memory-resident array pair `vb[1] * 8 + vb[0]` can be a strength-reduced index plus a base pointer never given a register. Loops over `rot[n]` with `n++` keep `n = 0` as a stack store (sw zero), reloaded for the loop base (lw; sll 3; addu). The base pointer stays in its own stack slot (stored right after the load, reloaded before the loop) only when it is assigned inside the if from the field read the if already did: `if (s->f != NULL) { n = 0; rot = s->f; ...`. `rot = s->f; if (rot != 0)` puts rot in a register and spills it at the call (61); a copy `rot = chk` merges into chk and uses its slot (110). Evidence 0x23ac-0x24b4. See also Q1069, Q0521, Q1124, Q0562.
