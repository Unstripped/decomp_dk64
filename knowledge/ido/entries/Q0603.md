The `u8 collisionCheckActorFloor(...)` callee-prototype steer in `actorMoveWithinZone` (12E800, round 4) can be replaced by a volatile return on another callee instead. So the steer controls how many callee return values are live and when, not the callee type itself. Look for the real liveness source before keeping such a steer.
