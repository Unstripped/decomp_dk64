uopt keeps one constant web per type of the expression that uses it. `x == 4` on an `s32` and on a `u32` are different constants; casting every read of a selector field to `(u32)` (switch included: `sltiu` instead of `slti`) merged the target's constant webs (330 -> 15 diff lines on `transformBarrelUpdate`). Stores of constant 1 share a web only when the destination fields have the same type (use the real header field types), a narrow callee parameter turns a constant argument into a fresh `li`, and `2` vs `2U` joins the case web of a signed vs unsigned selector. Balancing callee parameter types against selector types matched `tagBarrelActorUpdate`.
