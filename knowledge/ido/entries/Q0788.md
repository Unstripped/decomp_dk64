Constants that are only stored (store-only constant webs) take FP registers in source store order (the first stored web gets $f0), while as1 schedules the stores themselves independently. A dead test that only promoted one constant is replaced by storing that constant first in a natural order.

Evidence: mtxIdentityF (global/110F00.c, FAKE 1 -> 0): a column-major identity written with literals, stores in natural order.
