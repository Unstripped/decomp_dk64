`volumeTriggerSetPosition` matches declared `void` (its only caller, 42630, ignores the result), like its sibling `volumeTriggerSetEnabled`. Before keeping an `s32` that falls off the end (Q0260), check whether any caller uses the value; if none does, retype it `void`.
