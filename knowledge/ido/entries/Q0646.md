In `camComputeEyeFocus` (201B0) the empty `if (gPlayerCount >= 2 && gSplitScreenMode != 0) {}` in case 0x36 keeps its global loads in the object (1942 vs 1929 instructions without it). An empty guard whose condition reads globals is not removable by C semantics alone; check the instruction count before calling it a steer.
