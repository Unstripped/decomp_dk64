Per-axis endpoint arrays (`f32 px[2]` = both endpoints of one axis) retire a do{}while(0) copy block, not only the frame homes. Array elements are non-vreg (Q0562): `x = px[0]` is not copy-propagated into the lerp, so each pass reloads (0x3834-0x3848, 0x38b4), which is what the do/while(0) block forced for the address-taken scalars. Homes are unchanged (arrays 8-aligned in declaration order).

The operand order matters. The textbook `a[0] + (a[1] - a[0]) * t` matches: cfe compiles a top-level `+` of array elements with its operands swapped. `(a[1] - a[0]) * t + a[0]` and `+=` score 3, and a one-statement lerp `x = ((px[1] - px[0]) * t) + px[0]` scores 30. actorTestNodeSegmentCollision fdiff 0 (LeverScout26 + CleaninputRemapButtons).
