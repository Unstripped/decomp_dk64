File src/bonus/2690.c, bonusSearchlightSeekGameUpdate (both kept). EXTENDS Q1049/Q0163: in one uopt block a variable's priority is its def-plus-use count; a value the target reads once (1 def + 1 use = 2.0) can outrank a twice-used shared field load (3.0) only through a counted ref that emits no code, and the only known source is Q1049 (a first assignment from that shared load). So count the target's reads of the register before respelling: a once-read value that must beat such a load means the reused local is unavoidable ($f12 read only at 0x5e4c; honest error 2.0 in every template). CONFIRMS Q1049: a single-use arithmetic local feeding another local's load-holding definition is copy-propagated and leaves no candidate (targetVelX 90|0 at bit 163).
