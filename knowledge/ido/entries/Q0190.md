handlers keep state in `cs->unk0`. `if (*(T **)cs == NULL) { n = alloc(k); *(T **)cs = n; n->a = 0; } p = *(T **)cs;` (re-read through the cast, no cached `T **`) reproduces the original; a second copy of the pointer (`move a0,v1`) needs a separate `q = cs->unk0` with the field expression re-read for some uses; `p = *(T **)cs = alloc(k);` fixed an 8-byte-short frame.
