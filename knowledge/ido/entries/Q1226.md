When uopt rebuilds a counted loop's exit from a strength-reduced value (K - j*8) the constant goes first (`bnel s2,s0`, uneq{135}{iv}); a source `y != K` test puts the variable first, a natural replacement for a `^ 0` steer (Q0693). The trip-3 loop with a call is not unrolled (arcade/0 arcadeDrawStage4Background).
