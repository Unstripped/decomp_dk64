When the target derives a loop end from the base register (`addiu s1,s0,84`) instead of materialising `lui`/`addiu %lo(sym+N)`, no data-bound rewrite helps: every C form whose end is a compile-time address (sized arrays, sizeof bounds, index loops, end-pointer locals) folds to the constant address. Only a non-constant expression (such as an `(s32)` round trip) keeps the derivation.

Evidence: arcadeDrawStage3Background (arcade/0.c).
