When m2c shows a ternary that calls the same function twice, the source is gbi.h's `MIN`/`MAX` macro with the call as an argument: `MIN(c, f())` / `MAX(c, f())` expand to the same ternary, call `f` twice, and give an identical object. Write the macro instead of the expanded ternary. Related Q0778, Q0988 (MAX/MIN in other shapes).

Evidence: global/103AB0.c lensFlareAddSource and lensFlareDrawSource (unit Polishglobal103AB0, merge 0dad2ce0).
