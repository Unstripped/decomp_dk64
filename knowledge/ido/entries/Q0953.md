In `lightUpdateFromActorLighting` (src/global/8F4B0.c, ud2fe4), a forward `goto` jumps from one switch case into a shared tail in another case. The shared tail was re-verified at 0xec-0x150. The only spelling that matches without the goto is a Duff-style `if (0) { case N: ... }` block inside the switch. That is a dead-if steer, not a structured rewrite, so it does not count as removing a hack the way the Q0591 replacements (`for(;;)`+break, switch in body order, structured if) do. If the only alternative to a cross-case goto is `if (0)` wrapping a case label, keep the `goto` and record the shared-tail evidence. Treat the `if (0)` form as a hack too.
