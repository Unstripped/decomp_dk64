Under the shared `u8 flagGet(s16, u8)`, tagBarrelCheckKongFlag (global/80150.c) stores the result into an s32 struct field, which shifts the later ugen ring temps by one (t0/t9/t1 -> t1/t0/t2). The other 6 callers in the file match with the shared prototype; only this function needs the local `s32 flagGet` declaration.
