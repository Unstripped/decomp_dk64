In `schedDlDebugDump`, IDO emits `D_807F0D20 = D_807F0D14 = D_807F05A4` stores in the reverse of target order; spelling the D14 then D20 assignments separately restores the target assembly ordering. Define each static once: removing duplicate definitions restores 528 rather than 560 data bytes. The remaining full 54 is text 8 plus 46 non-normalized local-static relocation diagnostics, not 46 proven bad addresses.

A chained `a = b = x` stores `b` first: to match stores to 0x6C then 0x70, write `unk70 = unk6C = x` (`camUpdateFollowHeight`).
