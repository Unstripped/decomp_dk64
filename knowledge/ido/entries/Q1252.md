File src/global/42630.c, csCmdExec 4f1968. Extends Q1233 (see also Q1183, Q1196, Q0914): once cfe emits an address-of a parameter, uopt keeps that parameter out of its candidate table even when uopt later deletes that code. Evidence: `s32 pad0;` + `if (0) { asset = (void *)&csId; }` fdiff 0 (keeps `lh t5,210(sp)` reload at 0x3694, sel at sp+0xB3); `void *dm; if (0) { dm = &csId; }` fdiff 0; live `csId = *(s16 *)&csId;` + pad scores 0; without the pad word 59. Contrast: bare `&csId;` is dropped by cfe (Q1183) and `*&csId` folded there (Q1196).
