Extends Q1589. Two FAKE dead tests went away by respelling a branch the function already has, with no dead test left:

- actorUpdateNodePositions (global/70FD0.c, merge 35e626ce): inside the node loop, `if (node->mtxOffset == -1) {...} else {...}` as `switch (node->mtxOffset) { case -1: ...; break; default: ...; break; }` (the form its sibling function already uses) lowers the loop-invariant `mtxBase` (cand 29, 2.75) below the constant -1 (cand 70, 3.33): `li s5,-1` at 0x5800, `lw s6` at 0x582c, as the old dead `if (mtxBase) {}` did. Default-first scores 25; `while` vs `if` + `do-while` alike.
- modelSlotResolveAssetTextures (global/36880.c, merge aa034500): `if (sel == K) {...return;} else {...}` as `switch (sel) { case K: ...; return; }` with the other path after the switch gives the extra block after the last call (fdiff 0). Adding `default:` scores 103; the same early return as an `if` 64 (= removal). Lead ruling: ordinary C under R3 (one-case selector switch).

Tool: `tools/variants.py scan --recipes switch` generates both forms (skips bodies containing `break`). A one-case switch on a value nothing else switches on is a dead read in another spelling (Q1600): only respell a branch the target really has.
