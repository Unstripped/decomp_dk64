`D_8074D0C4[i]` and `D_8074D0C6[i]` (`sll 2`, `lh` each) do not need two array symbols. One struct array that reads `.unk2` emits `lh 2(reg)` against `D_8074D0C4` where the split form emits `lh 0(reg)` against `D_8074D0C6`. The linked words are identical; only the relocation symbol and addend differ in the `.o`, so the result is RELOC-EQUIV, not an objdiff mismatch (7A510 at ab138f97; the same holds for `D_8074C604`+4). Separate symbols are needed only when you want byte-identical `.o` relocations.
