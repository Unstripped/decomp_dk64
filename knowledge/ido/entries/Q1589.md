In modelPendingQueueInsert (global/36880.c) the 752 constant web (3.33) outranked the gViewportCount ucvt (3.00) for t2. Replacing `if (slots && slots) {}` with an inner `switch (obj->updateMode) { case 6: ...; default: ...; }` (R3 one-case selector, one more CFG node) drops 752 to 2.50, so gViewportCount takes t2 (lbu t2 0x99f8), 752 t3, 6 t4. Default-first does not work (22).
