When one local (snapshotted from a `void *`) is written through different per-kind layouts in a switch, replacing it with one typed local per kind creates one web per local and changes colouring (Q0501). A single local typed as a union of the kind structs keeps one web: byte-identical code with per-kind field names and no casts.

Evidence: global/36880.c (merge 62fdbc30).
