A global read assigned to a callee-saved register variable normally assembles as `lui s5,%hi(G)` / `lw s5,%lo(G)(s5)` (ugen passes the str's destination as a hint). The target form `lui v0,%hi(G)` / `lw s5,%lo(G)(v0)` is a shared ugen node: eval.p discards the hint when `ref_count >= 2`, so the load goes to $v0 with `move s5,v0`, and as1 later folds the move into the load but keeps the `lui` in v0. uopt output shows it as `lod G; str Rmt $v0; lod Rmt $v0; str Rmt $s5` plus a second consumer that leaves no code (a dead `fjp` to the next label). Two plain reads of a *variable* candidate (`cur = G; if (G) {}`) are NOT CSE'd (two separate `lod G`); both reads must be `ilod` of the address, e.g. `cur = *(u32 *)&G; if (*(u32 *)&G) {}` (a pointer local `pp = &G` also works but adds a stack slot and 8 frame bytes). The dead `if` adds a block boundary that reshuffles web allocation (text 2 -> 24); the earlier dead read elsewhere in the function (`if (G) {}`) then had to be respelled `if (G && G) {}` and the `i = 0` / flags initializer order came back. Search method: a reduced-TU score (tools/deadsweep.py score --body) runs ~45 compiles/s on 16 cores, so a matrix of head forms x dead-statement spellings x removal of old FAKEs finds the combination in under a minute. Toy files (cc -O2 -K, udis t.O) show the uopt ucode quickly: `tb`: cur = gA; other = gA; gC = other gives the same lui v0 / lw s0,0(v0) pair.
