2F550 clipPolyAgainstAxis: `for (i...) { cur = &src[i]; ... prev = cur; }`: uopt strength-reduces `&src[i]` (s0 from 0x3bc4, `addiu s0,s0,6` 0x3cb8) and `cur` stays a separate web (`move s8,s0` 0x3be0; `prev = cur` -> `move s1,s8` in the exit delay slot 0x3cc0). Stepping the pointer (`prev = cur++`) loses the copy register (srcCount takes s8, 16 bytes shorter). Replaced the base's redundant alias `last = cur; ... prev = last;`.
