arcadeUpdateOilDrumEntity (frame 0x28): one cfe temp word (-8 = sp+0x20) serves `param2 = !param2`, all three two-label switch selectors and both post-increment compares (`animTimer++ == K`, `animTimer++ > 40.0f`). cfe allocates it after every declared home, block-scoped ones included, so any extra declared word pushes it to -12 and the a1 spill 0x1c -> 0x18. Related measurements: a pointer local `T *p = &arr[param]` used for every access is copy-propagated back (its spill stays a temp) but its own home still costs a frame word (0x28 -> 0x30); the `register` storage class does not drop a local's stack home (same score at every position, also in 3E10); an inline ternary operand (`y += c ? a : b`) costs a temp word while `step = c ? a : b` does not (arcadeUpdateRetractableLadder, where the reuse raises step's adjsave 1.5 -> 2.5 above the field reloads (2.0) and decides $f0/$f2). A function-local `static` in place of a register-only local keeps every stack offset but stores the value to .bss after each assignment (`sw v0` after the call), so it cannot stand in for it.
