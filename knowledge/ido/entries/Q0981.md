This is a second instance of Q0857, in sfxUpdateLevelAmbient (global/7130.c). The match used dead `if (G && G) {}` and `if (G) {}` tests on the file's globals. Turning the global into a function-local static makes those tests unnecessary: the instructions come out identical, and only the .bss relocation words differ. The stand-in check is standin_carve_7130.c. A file-scope definition does not do the same thing, whether it is `static` or not: the code stays unchanged and the dead tests are still needed. So the lever is specifically uopt treating a function-local static as a local static variable, not just having the TU own the definition. Using it means the TU has to own its .bss, as in Q0857's yaml carve. That carve was deferred (pending.md), so the dead tests stay in the merged source for now.
