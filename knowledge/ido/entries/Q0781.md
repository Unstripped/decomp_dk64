Several accesses `routeRows[index].field` written out in full share one CSE'd address computed base-first (`addu a0,t0,t8`), whereas a named pointer `row = &routeRows[index]` gives the offset-first order. When only the addu operand order of a shared element address differs, switch between the repeated expression and a named element pointer.

Evidence: raceOpponentBehaviourUpdate (race/0.c, FAKE 6 -> 2). Same function: moving an existing pointer recomputation right after a branch drops vx's live-block count 30 -> 29 and flips the FP candidates' order (Q0163/Q0523).
