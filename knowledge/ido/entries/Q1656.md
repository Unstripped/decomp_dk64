This refines Q0510/Q1557. When `x + 1` appears only in an if test, it lives in t6 for that block and the return recomputes it. Storing it to a local first, even one read only by the test, makes the later block reuse it in one register: the no-local form scores 3 lines, the stored form 0. raceGetNextWaypointIndex 0x0-0x10: `addiu v1,a1,1`, `beq a0,v1`, `move v0,zero` (delay), `jr ra` / `move v0,v1`.

The return must value-number to the stored expression, either by recomputing `curWaypoint + 1` (the kept FAKE) or by spelling both through one function-like macro `NEXT_WAYPOINT(i) ((i) + 1)` (fdiff 0). The macro form was ruled a respelling of the recompute steer (director R1, 2026-11-25), so the FAKE stays.
