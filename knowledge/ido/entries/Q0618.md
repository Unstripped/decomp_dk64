In `lightApplyToActors` (5E2F0), `*(s16 *)((u8 *)actor + 0xCE)` and the real field `actor->unkCE` compile to the same code except for the frame size. An unused `s32 pad;` local (untagged, frame-size-only) declared before `factor` restores the match (permuter output-0-1). When retiring a cast pun leaves only a frame-size diff, add an unused scalar pad rather than keeping the pun.
