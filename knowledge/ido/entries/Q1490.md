A `& 0xFFFF` mask on an s16 global assigned to a u16 local keeps the global's own `lh` load (the value sits in t9 between the `lh` and the `sh`); the unmasked `u16 id = s16global` lets cfe load it with `lhu`. An `s16 id` keeps `lh` but moves the value to v0, and reading the global without a local changes the list pointers' registers. A target `lh` whose value is stored as a u16 points to the explicit mask. Related Q0654 (signed loads pin a field's type), Q1301.
