A class-2 dead guard (`if (v) {}`, `if (G && G) {}`) that works only with that variable raises or lowers its uopt priority. The natural source usually differs in use count: the original re-reads a struct field/global where the draft reuses a cached local (or vice versa). mapGridQuadContainsPoint: edge vectors from `q->x[j] - q->x[i]` instead of vx/vy removed 7 guards; cannonUpdate: look-at z as `gCurrentActor->z + cosOff` removed 2; func_8068F72C: `(ACTOR->unkAC - fa0)` instead of `(sp54 - fa0)`; actorTargetEntriesUpdateSfx: `D[i].f` at each use instead of a cached entry pointer (and stride local). Class test: replace the guard with an unrelated codeless `if (local) {}` at the same spot; if that also matches it is class 1 (empty block/split), else class 2. The fixed permuter run from a FAKE-free copy finds these quickly.
