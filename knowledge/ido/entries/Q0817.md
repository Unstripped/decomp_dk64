For a u8 parameter passed on the stack and tested twice around calls, a single `*(u8 *)&param` read in either test suppresses the ucvt (widening) candidate for the whole web, so both tests reload the byte with `lbu` from the stack home. Without it uopt CSEs the two reads into one callee-saved register (ucvt{param} candidate), so the plain `param != 0` spelling no longer matches there.

Evidence: actorCollisionResolveSurfaceHit (global/7BBD0.c).
