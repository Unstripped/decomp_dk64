split a reassigned local into two locals (`loadOverlay`'s biggest gain) or one reused local into loaded-value + result (`textBoxRenderNode`); merge non-overlapping locals to shrink an over-large frame (`dest == source` FP ops such as `div.s fs2,ft1,fs2` hint two source variables are one); read a struct field directly rather than through a copy local (copy blocks load+`sll` CSE and `negu` derivation); re-read a field after a compound store for a separate value candidate; a value used in a compare and as a call arg: test the re-read expression and copy it into a second local only inside the call block (`lw v0; move a1,v0`). A named temp CSEing a shared product (`t = -a * inv; m10 = b * t; m02 = -t;`) reproduced spill roles; a named FP local reused for every quotient wins `f0` first-fit.
