cfe folds a cast on a literal argument (`f((u8)2)` into an s32 parameter) to the plain literal, so it has no effect wherever it is placed. Only a narrow PROTOTYPE parameter, where the call itself inserts the conversion, lets the argument reuse an existing constant web.

Evidence: hudPauseMenuRender (global/ACDC0.c): the target passes the constant via `move a3,s8` at 0x1638/0x16b8; every call-site cast placement scores full=400.
