REFINES Q0875, Q0944 (2026-11-17f A2F10 correction) and Q0798 (see Q1167, Q1159): for a jump-table switch on a plain variable uopt treats the switch value as `add(sel,0)`; that copy stays in a register only when a later case-block read of sel is the LAST use of sel on its path (the read then uses the copy: `str v0` at the dispatch, `lod v0` at the test); if sel is read again later on that path (a ternary branch, a spare argument in a1) the copy is never stored and the test reads sel's own register. Block position does not matter (two tests in successive blocks both read the copy). No-op casts and `switch (sel = expr)` behave like the plain variable; a selector that is already an expression with a different value (`sel ^ 0`) is not wrapped: uopt emits xor and the case reads stay on sel.
