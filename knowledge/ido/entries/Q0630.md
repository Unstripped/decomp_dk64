A loop walking a pointer up to a cast of the next global symbol is uopt's loop-test replacement of a counted `for (i = 0; i < N; i++)` over `G[i]` (`actorGlobalCallbacksDispatchAndFree`, 7CA80). The counted loop compiles to the same instruction words, with the end pointer relocated as `G + N*size` instead of the next symbol, so the object is relocation-equivalent (objdump -drz raw words equal). This retired the punned-cast walk.
