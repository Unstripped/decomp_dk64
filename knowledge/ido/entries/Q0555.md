Two unsigned uses of `~0x3FU` in one block become one coloured constant web (`li v1,-64; and v0,v0,v1`). A third unsigned use placed after calls stretches that web across the calls, where no caller-saved register is free and the web is not worth a saved one, so it stays uncoloured and every use emits `li at,-64; and rd,rs,at` like the target. In `eepromSaveRecords` (leftovers revisit 13) the third use is a dead `if ((u32)D_807EDEAC & ~0x3FU) {}` after `osWritebackDCacheAll();` (any initialised value works; tagged FAKE). Signed `-64`/`-8` masks are a separate constant candidate (`{1555|0}` vs unsigned `{1555|1}` in `uopt_trace.sh -l 5`), so changing a mask's signedness moves its uses between the two webs. Related levers from the same match: a dead redefinition of an operand right after `b = expr` (`offset = 0;`) stops copy propagation of b's value into a later index, so b stays the variable (Q0546 family); `q = (u8 *)((u32)G | 0); if (*q != 0)` keeps an unfolded `lui; addiu; lbu 0()` with ring temps where `if (G[0])` folds to `lbu t,%lo(G)(t)` (Q0453 `| 0`).
