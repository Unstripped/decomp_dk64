If code between a narrowed index's definition and its only use (a call argument) modifies an operand (`height -= 4;`) or takes its address (`&height`), uopt no longer folds the index into the call. The index then stays a v1 variable ahead of the multu (104F0 eepromSaveRecords 0x1bf4-0x1c1c). 6b7e71 permute: baseline 3048, best 195, 900 s.
