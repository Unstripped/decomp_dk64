a global read in a dominator and written later, or an extern RMW (`A--`), gets its address hoisted into a register; a dead read `if (G && G) {}` / `if (G == 0) {}` right after the first reference restores separate `lui`/`%lo`. uopt hoists an address across a call only while a callee-saved register is free.
