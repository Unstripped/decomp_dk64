boss/0 bossPieceStep: `if (!pieceIdx)` makes the target spill a1 to its home (`sw a1,0x34(sp)` 0x644) and test a reload (`lw t7,0x34(sp)` 0x724, `bnez t7` 0x75c); `pieceIdx == 0` keeps the value in v0 (fdiff 1). The `!` form is original, not a steer.

Correction (2026-11-24b, LeverScout, checked in expected boss/0_armydillo.o): pieceIdx's own home is 100(sp) and is read `lbu ...,103(sp)` (0x578/0x5dc/0x5f4/0x620/0x708/0x744) in both spellings; the `sw a1,52(sp)` at 0x644 stores `pieceIdx << 1` (`sll a1,t6,0x1` at 0x624, the s16-array index) to a uopt spill temp, and the test is `lw t7,52(sp)` 0x724 / `bnez t7` 0x75c on that reloaded scaled index, not on the argument. So `!u8param` lets uopt test a CSE'd scaled copy of the parameter (a spilled temp) where `== 0` tests the value in v0. The `!` form is still original.
