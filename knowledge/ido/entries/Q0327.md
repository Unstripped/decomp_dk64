`if (flag) return expr;` then falling off the end keeps `flag` in `v0` (`return flag;` uses `v1` + `move`); a `volatile int` return type returns `&&`/`||` straight in `v0` (cfe warning 651; `volatile s32` fails); `a = ((a + 8) & M) - b` makes a fresh temp, `a += 8; a &= M; a -= b;` stays in place.
