Two colouring/order rules: (1) a field load that uopt CSEs as a temp ranks below a declared variable, so the same value as a named local can win an FP register the temp loses. (2) A commutative multiply by a CSE'd quotient, `x * (110.0f / dist)`, is emitted `mul.s d,scale,x` whatever the source order; only a named local for the quotient keeps `x * scale`.

Evidence: bonusSearchlightSeekGameUpdate (bonus/2690.c): as a temp `subExt->velZ` gets $f18 and stickY $f16; as a variable velZ gets $f16 like the target.
