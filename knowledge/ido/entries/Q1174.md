The body of a `do { ... } while (0)` statement macro adds the same two no-code basic blocks as an empty dead `if`. In boot/3D20 vsprintf the tagged `PUTC(ch)` macro replaces two dead tests: 2829ec in the numeric zero-pad loop (the in-loop 48 piece gets adjsave 0 and `li t7,48` is rematerialised at 0x88c) and u8169d in the exponent-sign else arm (exp/10%10 is computed before `li t9,43` at 0xccc). Used at all 35 stores it costs 94, so choosing the char-literal stores is a codegen decision and the macro stays `// FAKE` (d0cc22).

In a `for` loop the store must share the for header's line (`for (; width-- > 0;) PUTC('0');`) so that as1 schedules the loop test above count++/sb; splitting the lines gives 2.
