For a float, the abs ternary `x = (x > 0) ? x : -x;` and the statement `if (!(x > 0)) x = -x;` give identical code, so either can replace the other. The comparison is not free: `x <= 0` and `x < 0.0f` both differ. Related Q0426 (an int `0` in an abs ternary gets its own `mtc1 zero`).
