an address passed as a callback (`func_8071498C(func_8071720C)`) must be declared as a function, not `extern ... D_8071720C` with `&`: the function form changes IDO's loop-invariant hoisting order (its `lui`/`addiu` before a data array's, or before a `.rodata` float's).
