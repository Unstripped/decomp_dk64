In tagBarrelActorUpdate (site 71b822), the empty `default: break;` adds no code. It only puts a source-line record (`.loc 453`) on the block before the loop latch, where uopt places the loop's end-pointer recompute. Without it, the recompute shares the for line with the pointer increment, and as1 swaps the increment into the `bne` delay slot. 178 variants on the no-default and continue forms and a 900 s permuter run found nothing; the empty default stays FAKE.
