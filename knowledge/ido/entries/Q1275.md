File src/global/104F0.c, eepromClearSlotData afefd3 (fixed). Extends/retires Q0425 here (see Q1141, Q0902, Q0772): copying a K&R `unsigned char` parameter into a `u32` local needs no conversion, so the local reduces to the parameter byte in one callee-saved register, and passing the u8 parameter to two consecutive u8 arguments gives a fresh `andi aN,sX,0xff` per call (0xffc/0x100c/ 0x1014); with an `s32` copy the two narrowings become one shared spilled value (24; u16 10). Same idiom in the matched sibling eepromSetCurrentSlot (`u32 slot = slotId`). Related: eepromValidateSaveSlots re-narrows a shared u8 in s0 at each u8 parameter (0x15d8, 0x15ec, 0x1624).
