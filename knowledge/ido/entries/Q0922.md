bonusLightFlashGameUpdate (bonus/2690.c, base 68c14139, carve merged 660b3162, ledger 3e09d99f, commits c02f22/190d09/e5ec5b/300787/b1a373) went from FAKE 5 to 0. Each of its globals uses a separate `lui`/`%lo` pair at every access with no shared lda base. That pattern marks a function-local `static`: uopt keeps it a native S variable without an lda web (Q0761). Extern and file-scope spellings always build one lda web. The FAKEs fought that web with punned `((s16 *)&D_8002D8F4)[k]` stores and dead-test/`| 0` one-liners. IDO places the statics after the TU's initialised file-scope data at +0/+4/+8. D_8002D8F4/F8/FC become sFlashResetTime/sDarkBeepTimer/sDarkTicks at .data +0x34/+0x38/+0x3C. For this to work, the TU's .data must be carved into C (yaml `[0x98C0, .data, 2690]` + `[0x9910, data, 9010]`). Counter-example: in bonusPerilPathPanicGameUpdate (d61c1f), making D_8002D904 a static local adds an extra `lui` + `sb`, so check each access pattern. Rule: every FAKE that cites Q0332 (keeps lh/sh from sharing a hoisted lui/addiu base) is a static-local candidate.
