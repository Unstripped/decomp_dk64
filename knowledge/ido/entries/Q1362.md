NEW, EXTENDS Q0710/Q0523/Q1194 (uopt colouring; corrects the history's "empty guard steers regalloc" reading): a global's address can only be pushed out of the lowest register if a value in that register overlaps it. A constant (address) candidate's range is the union of every block where it appears, even across sibling arms that never reach each other. `if (D && D) {}` in another arm adds its block to that range, and because it reads D twice, the read becomes a candidate holding v0 there, so the address range cannot use v0. A single `if (D) {}` also adds its block, but its single-use value is not a candidate, so it has no effect (score 5). Colouring then takes the lowest register no neighbour holds. Evidence: guard read lr 24 in v0 (bbs 1/2); with the guard the address range (lr 182, bbs [1, 63, 64]) gets v1; without it bbs [60, 61] get v0. The permuter zero works the same way inside block 61.
