Spelling an element of a global array through an identity cast, `&((MapChunk *)gMapChunks)[i]`, matches where `&gMapChunks[i]` and `gMapChunks + i` do not: cfe builds the cast as a separate expression that is never CSEd against the plain `gMapChunks` load, so the base is re-loaded (`mapChunkReleaseAndAdvance`, `mapChunkEffectSetFlag`, `mapChunkFindNodeAtPoint`). Keep the cast as a view only where this is the evidence.
