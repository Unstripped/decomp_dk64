In mountedBarrelUpdate case 0x113, `x = PICK_MIN(PICK_MAX(K1, t), K2)` is original: the target re-evaluates the inner select at 0xa10-0xa30. Respelling it as if/else changes the case's own code (score 207 with the comma kept).

`c ? (v = a) : (v = b);` as a statement compiles like `v = c ? a : b` (106): the value is discarded, so it is not the shared f64 temp that the comma form uses.
