Converting the rodata pragma D_8075A740 (A8400, 8 zero bytes read as a u16) to C (2026-11-18 static-data unit): `const u16 D_8075A740 = 0;` compiled into .data (16 bytes), so the TU's .rodata came out 592 bytes instead of 608 and fdiff failed. `const u16 D_8075A740[4] = { 0 };` lands in .rodata and matches (reader: `D_8075A740[0]`). Q1003 shows the same for `static const f32`; it holds for non-static const scalars too. Const aggregates (arrays, structs) do go to .rodata (Q0834).
