In hudDrawRollingCounter (global/90D80.c, 8c076a), passing the string literal `"1"` to a `const u8 *` parameter triggered cfe warning W709. Declaring `static const u8 sOneDigit[] = "1";` inside the function and passing that instead removed the warning (cfe warnings went from 2 to 1) and kept .rodata byte-identical. This only works because `"1"` is the last of the function's literals, coming after `"%d"`, so the local static is emitted where the literal would have been. Moving the same array to file scope changes the .rodata order (fdiff 1). The sibling literal `"HIT"` in renderHitCounterHUD (f2ca09) fails with the same spelling because `"%d"` comes before it there, so that site still needs a different fix. Check where a literal falls among the function's .rodata strings before turning it into a static array. Unit PolishglobalViews, merge 5a845572, ledger eaa11007, base f5885203.
