a `u8` parameter keeps a constant argument separate from a switch/compare constant in the same loop (`li a0,1` vs `move a0,s4`), and makes a hoisted constant pass as `andi aN,sK,0xff`; an `s16` parameter re-extends a register-held `s16` at every call (`sll/sra`), so a target with a plain `move` needs `s32`. Casting the argument does not substitute for the prototype.

A local `s8` callee prototype plus `switch (u8 + 0U)` can both exist only to keep a constant-1 argument out of the selector web; with the callee's real `u8` prototype a plain `switch (effectType)` gives the same separation and both hacks go (`effectSpawnActorBoneEffects`).
