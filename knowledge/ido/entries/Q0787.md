A single index `cells[cell]` with `cell++` running across two nested loops is strength-reduced by uopt into a byte-offset induction variable plus a per-column pointer walker; a hand-written byte offset + pointer pair in m2c output is the decompilation of that index form. It fails only alongside a separate element walker (`e++`). Also, with unconstrained candidates, `min = x; max = x;`, `min = max = x;` and `max = min = x;` give three different register assignments (first-appearance order).

Evidence: meshComputeVertexRanges (global/10E1D0.c, FAKE 4 -> 1).
