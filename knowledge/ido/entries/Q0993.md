Fields of a local struct are separate scalar candidates to uopt, so grouping steer locals into a struct (`struct { s32 uls, ult; u32 lrs, lrt; } tile`) produces the same object and never retires a hack. An auto-struct initialiser (`= { 0, 0 }`) additionally emits an aggregate copy from `.rodata`.

Evidence: dlAppendTextureLoad (global/1135F0.c): the struct-wrapped steers score 0 (unchanged object); the initialised form adds the .rodata copy (836 lines, reloc=2).
