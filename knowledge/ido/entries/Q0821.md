Even unoptimised, IDO 7.1 `-g` folds constant offsets: an array-member chain with a constant `-1` index offset compiles to the same code as the punned word arithmetic, so `-g` files can take typed libaudio member chains freely.

Evidence: global/13A7A0.c: `p->instArray[0]->soundArray[i - 1]` == `((T **)((u8 *)((void **)p)[3] + i * 4))[3]` (merge ede40277).
