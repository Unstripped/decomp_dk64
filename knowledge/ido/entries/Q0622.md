In `raceGetRoute`/`raceGetWaypoint` (A960), the target hoists the `items` load above the `D_8002FCF0 == NULL || idx >= count` test. `T *e = &D_8002FCF0->items[idx];` at the top, followed by the check and a reassignment `e = &D_8002FCF0->items[idx]; return e;`, reproduces it; removing the early calculation without a replacement drops the hoisted load and changes scheduling. The natural form is a defensive declaration initialiser `T *e = NULL;` (the early-exit path returns NULL): the local is a register candidate live from entry (Q0795).

Corrected 2026-11-14 (HackraceGetRoute): the earlier claim that no natural spelling exists is superseded; `T *e = NULL;` matched raceGetRoute (FAKE 3 -> 1, merge 6b18779b, director-accepted).
