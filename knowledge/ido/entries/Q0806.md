When a function reads a global struct partly through split splat labels and partly through a struct pointer, the pointer looks like a steer. Once every field the function reads goes through the pointer, the pointer is ordinary C and the object is RELOC-EQUIV: only the LO16 addend moves from the split label onto the struct offset. Mixed forms fail.

Evidence: jetpacRocketItemUpdate and jetpacBonusItemUpdate (jetpac/3480.c): D_8002F054..78 read as player->y/vx/vy/state/boxX1..boxY2; pointer plus split labels 44 diff lines, direct struct fields 112.
