every `switch` creates a compiler temp below all declared locals; an if-chain with the same compare order avoids its home word (`mapTreeFrameUpdate`). Case source order follows the jump-table block layout; `case 2:` before `case 1:` gives `beq/beql/bnel` plus an argument copy. A `switch` on a u8 local in `playerUpdateCommon` (CEAE0) adds the same 8-byte temp slot in either case order; an if/else-if chain costs 16 bytes there, so the three gotos stay.
