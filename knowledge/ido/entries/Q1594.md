Q1586 (per-block element pointer replacing a class-2 dead read) transferred to three functions and failed each time on a precondition. Check the target first:

1. Base reloads: count `lw tN,0(<lda reg>)` reloads between stores. mapChunksInitFromMapData (global/55B20.c) reloads the global base before every field access (42 `lw tN,0(s3)` at 0x2c8-0x764): the original indexed the global per statement and a pointer removes all reloads (403).
2. Several access blocks: menuHandleHighScoreNameEntryInput (menu/3E10.c) computes the element address ONCE at the join 0x72d0-0x72f4, reached also by the non-press path (`bnez` at 0x7298). A pointer at a sub-block head moves the computation there and spills it (147: entry at sp+40, frame 0x30 -> 0x40); every other placement 62-200.
3. No shared CSE across a switch head and an arm: slotQueueDrawLabel (global/FCCD0.c) shares one address CSE between the switch head and an arm; the pointer is one variable across both blocks (= removal colouring), adds a home word, and loading the global straight into it uses one fewer t-temp (later t-regs shift). 33 bodies, best 28 vs removal 7.
