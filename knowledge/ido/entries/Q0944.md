In `raceOpponentBehaviourUpdate` (src/race/0.c, ledger-only 5c8c62b7, base 3144bc00; reconstructed nohit with 3 sites kept), cfe gives all of a function's switch statements ONE shared selector temp. Here that is -72vreg for the case-10, status-0 and status-5 switches, and `projectileRenderSpriteRing` uses -276 the same way. If both switches select on their fields directly, that temp (adjsave 2.33) loses `v0` to the status-0 load cvt (2.67). The cvt also carries the compare-0, the phase store, the temp store and the case-0 `addiu`, and the result is 19 lines off. A user selector variable survives copy propagation into the shared temp only when it has a second definition. The base `u32` selector qualifies because it is re-defined in case 10. `sel0 = unk35; phase = sel0; switch (sel0)` colours `v0`/`v1`/`a0` correctly but emits the copies in the order `move $2,$3; move $4,$2`. as1 then fills the `beqz` delay slot with the phase copy, leaving 4 lines off.
