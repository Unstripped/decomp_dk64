`T *p = (T *)arg1;` makes `p` a saved-register candidate; when the target keeps params in memory use a `#define P ((T *)arg1)` cast instead. A K&R definition (`void f(a, b) T *a; s16 b; {`) can narrow a parameter under a file prototype with `s32` (warning 642); pointer parameter types must be spelled exactly as in the prototype. A K&R `volatile u8` parameter keeps `lbu` from its home slot.
