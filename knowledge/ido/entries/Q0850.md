`if (flag != 0)` on a u8 local inside a loop whose body calls a function makes uopt build a zero-extended register copy before the loop and spill it to a new slot (lbu v0,0x87(sp) at 0xad0, sw v0,0x50(sp), lw t4,0x50(sp) per pass; frame 0x90 -> 0x98). The bare `if (flag)` / `!flag` keeps it at its home byte, reloaded with `lbu t5,0x7f(sp)` each pass. Only the in-loop test matters. s8/char keep the home but load with lb. Q0384 records the same ucvt candidate for u8 parameters. Evidence: actorLightPulseUpdate (global/A2F10.c).
