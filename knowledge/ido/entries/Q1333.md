EXTENDS Q0887 (see Q0322, Q0401): a reload written after an if is placed differently from one written inside it. `x = G;` after an if whose taken branch stores through x (with x already holding G on the other path) is reloaded only on the taken branch, as a separate lui/lw %lo(G) pair outside G's shared address register. The same `x = G;` written inside the branch reloads from that register (lw s0,0(s2)).
