HackcsCmdExec8 (ledger f2483ca4, no merge), 42630 csCmdExec case 0x68: the Q1157 steer `b = (s32)D_807F61F0.hostActor; if (b) {}` works only with the hostActor FIELD load as its definition. Defining `u8 b` from the first `actorDespawn` s32 return value instead covers the same range between the two calls, but scores 10, the same as removing the line. So the steer is not the live range alone: the load of the field, which keeps the `&D_807F61F0` address web in a3 (0x2670-0x26a4), is what matters. Actor-pair array views of the two actor fields, early `break`/`return` exits and a declswap/width recipe scan of the body without the line also gave nothing below 10.
