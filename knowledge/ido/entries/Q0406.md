uopt colours candidates by descending `adjsave` (`uopt_trace.sh -l 5`); each loop use weighs ~1.5. A dead `if (x == 0) {}` / `if (x && x) {}` on a LOCAL (after its first assignment) raises it above hoisted loop addresses and `li` constants; deadsweep's global-only greedy sweep misses these, a script inserting a dead use of each local at every position (scored by `deadsweep.py score`) found them and matched three stalled stage-4/5 functions.
