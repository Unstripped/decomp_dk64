In schedSubmitGfxTask (14CF0) a size temp computed before the cache writebacks was tagged FAKE. uopt_trace shows it is never coloured: dropping it only shrinks the frame (sp-0x30 to sp-0x28). Inlining numCommands * 8 into the osWritebackDCache argument and keeping an untagged s32 pad for the 0x30 frame is fdiff 0. A local that only reproduces a frame size is a pad, per AGENTS.md, not a hack.
