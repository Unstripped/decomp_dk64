A call through a u16-prototyped parameter with an int-typed ternary argument stores the result and reloads its low half (`sw aN,off(sp)` + `lhu aN,off+2(sp)`) before the jal, adding a stack home that shifts registers in the whole function (the mechanism behind Q0697). A target that loads the ternary result straight into aN therefore proves the caller's declaration was wider than u16 (`// ORIG:`). In contrast, changing a literal argument's parameter type u8 -> s32 can change only CSE (the literal joins an existing s32 constant's value number): that is register-only evidence and not ORIG.

Evidence: bossArmydilloStep (boss/0.c, merge 70242923): `li a3,528` / `li a3,530` at 0x287C/0x2880 into jal 0x2898 (ea31b7 FAKE -> ORIG); hudPauseMenuRender (global/ACDC0.c): `li a3,2` -> `move a3,s8` at 0x1638/0x16B8 (6bd641/01af71 kept FAKE).
