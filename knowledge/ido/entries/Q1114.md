Same unit/function (extends Q0041/Q0270/Q0421): a reused f32 local holding constant 2.0 for several float ops in a block can be the int literal `2` at each use (`x * 2`, `... + 2`): one shared lui 0x4000/mtc1 per block, no strength reduction to add.s, and the local's slot is freed (air arm: int 2 = 0, 2.0f 131, 2.0 150; 0xf94-0xfa4, 0xfe0).
