In `menuUpdateElementTargetAndColor` (menu/3E10.c, fixed variants da4772/eed27b/787316/ac6bed), cases 6/7/18 pass `(s32)target->spawnX >> 2` to `menuEvaluateSelectorSpline`. Writing it as `idx = (s32)target->spawnX >> 2;` and passing `idx` reuses the shared switch variable. That gives idx a lower candidate number (33, adjsave 3.5). Because the argument register is forbidden to the other ranges, idx takes a1 first (`mfc1 a1` at 0x9490/0x967c). This replaced four dead `if` guards that had worked as uilod phantom v1 holders, lowering competing ranges (Q0561, Q0602). Treat it as a source-level lever that can replace dead-if steers. The byte-offset rgba puns became `(D_800337DC + idx)->r/g/b`, which adds base first per Q0816. `D_800337DC[idx].r` mismatches, so the tags stay, following the Q0816 precedent.
