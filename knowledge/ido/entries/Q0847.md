`sfxPlayOnFreeSlot(..., 1.0, ...)` with an f32 parameter emits a rodata double that is loaded and converted with `cvt.s.d` at run time; cfe does not fold it to a single-precision constant. Writing `1.0f` changes the object (16 more bytes of .text plus rodata/relocation changes), so a double literal at an f32 call site can be original. Evidence: raceManagerBehaviorUpdate (race/7BD0.c, merge 30e3ea61).
