A named variable that carries a value read before a branch to the compare at the rejoin creates a second register candidate next to uopt's own temp for the same expression. The variable takes the argument register first, so it cannot replace a dead-guard read that the target keeps in one temp. Evidence: FCCD0 slotQueueStateMoveToTarget 34e891 (cur in a1, ucvt{ilod} in a3, fdiff 5). Permute: baseline 339, best 50, 900 s.
