In `func_80025794`, double math with literal `0.8` inside an inner loop causes IDO to hoist `0.8` (`D_80027098`) into callee-saved float register `$fs5` (`$f30`) prior to loop entry. Unifying the reused float temporaries as a single local variable `fs1` instead of multiple separate locals preserves register allocation so IDO allocates `$fs0..$fs5` matching the original frame.
