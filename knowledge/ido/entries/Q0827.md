An `s32` counter advanced as `i = (u8)(i + 1)` gives the same code as a `u8` counter with `i++`: the explicit byte wrap is m2c's rendering of the u8 increment, so the counter can be declared u8 and the cast dropped.

Evidence: modelSlotTransformBoundsAndNodes (global/36880.c), identical code both ways (merge 62f01bf0).
