In enemyGridStateStep (global/C0EE0.c), the spelling `dx = col; dy = cell >> 2; dx -= st->gridX; dy -= st->gridY;` defers narrowing and has no dead tests. It places `cell >> 2` in t3 without the `(u16)` cast that earlier variants needed. This matches 8 rows as variant m_s32_sh_me_d_none. The extra temp register is not caused by the cast. The coloured `cell & 3` value keeps its register live across the shift, so the shift result has to go into another temp. This extends the named-temp approach in Q0758. Like the split-local shapes in Q0465, assigning the raw value first and subtracting the grid origin in a later statement changes register allocation without a width cast. This was a ledger-only cleanup in unit HackenemyGridStateStep2. The code is copied unchanged from base 546781fa, with record commit da5b8261.
