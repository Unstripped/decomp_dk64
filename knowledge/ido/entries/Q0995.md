When every target access to a global has its own `lui`/`%lo` pair and the decomp only gets that with a dead `if (G == 0) {}` / `if (G && G) {}`, the global is a function-local static in disguise (Q0922). With statics, also expect uopt to fold value tests: `phase = S + 1; if (phase == 7)` becomes a compare of S with 6, while the target's `addiu; li at,7; bne` comes from `S++; if (S == 7) S = 0; phase = S;`.

Evidence: arcadeUpdatePlayerEntity (arcade/0.c, carve c5ea18c1): the step timer and phase (D_8004BC80/D_8004BC84) became function-local statics and the dead guards went.
