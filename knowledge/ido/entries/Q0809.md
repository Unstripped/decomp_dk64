A dead definition that only raises a loop result's uopt priority (Q0385) can stand for a loop whose exit test was in the `while` condition: `do { ... } while (!match && pattern != 0); return entries;` keeps one loop exit and the result in its callee-saved register without the dead def.

Evidence: actorCollisionFindTableEntry (global/7A510.c): the target keeps the result in $s2; the do-while form retired the dead `entries = table->pattern` (3c9cea fixed).
