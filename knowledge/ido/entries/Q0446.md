`switch` bodies are laid out in source order while the compare chain is sorted; a value kept in a register across the dispatch is computed before the `switch`; code after an if/else may belong inside the branch that does not `b` to the epilogue; `if (!u8v)` makes no ucvt candidate while `u8v == 0` does; `s16` abs with one narrowing is `s16 y = a - b; s32 x = y; if (x < 0) x = (s16)-y;`; a u8 decrement with a distinct raw register needs `left = v; left--; if (v) {}`; `(f64)(f32)(u32)x` vs `(f64)(u32)x` changes the fixup; `return f(...)` vs a void tail call.
