A variable-index steer such as `D[zero]` with `s32 zero = 0` that forces a `lui`/`%lo` pair per access (the Q0922 static signature) can be retired by making the global a function-local static scalar, provided the data layout stays put: (1) it is the TU's last initialised `.data` object, so the static is emitted in the same place (Q0838/Q0947), and (2) its extra word was trailing padding (IDO pads `.data` to 16, so the section size is unchanged and the freed word returns as padding).

Evidence: audioCheckAiLength (global/6710.c): D_807454E8 as a static scalar at +0x228 still gives a 0x230 section. The result is only relocation-equivalent (LO16 `.data+0x228` vs `symbol+0`): verify with `fdiff --reloc-ok` plus the ROM gate.
