`while ((chan++, inst == NULL));` fixed a boolean-normalisation diff (`__n_initFromBank`); a `sw zero` between the `lw`/`lui` and `addu`/`lbu` of a table read is an embedded assignment `tbl[arg2 + (i = 0)]` (`n_alFxPull`). The comma's position sets the store's timing: in `menuHandleHighScoreNameEntryInput` the condition `(X = v, v >= 0x10)` cannot become `if (v != 1) X = v;` before the test or `(X = v) >= 0x10` (both fdiff 1; cleanup round 9).
