Limits Q1589/Q1591 one-node steers to non-nested competitors. Priority = savings / ((n-2)>>2)+2 over the n live blocks; when one candidate's live blocks are a subset of the other's and the contained one has higher savings, adding a code-free block to both grows the containing range's divisor at least as fast, so the order never flips.

Evidence: effectWaterInitNodes (global/63EC0.c): base {912} live in bb5/6 inside count {784} bb3/5/6...; every switch/label node placement kept base ahead (diagnose nohit, continue unit 2).
