uoptinput.c ends the current basic block at the next statement boundary once 20 variable loads (`varreflimit`) have been counted in it. A variable `lod` counts unless its value can be forwarded from an assignment in the same block; a load of `c` after `c = a - b`, and again after `c *= w`, counts each time because the earlier tree is killed. Long straight-line float code (matrix/lerp chains) therefore splits into several uopt nodes without any label, and since interference is per node (Q0451, Q0523) the cut points decide which FP candidates can share a register and how many coloured CSE values fit in a node. `.scratch/R13_sonnet_xhigh_3/cuts.py` reproduced the observed cuts of `modelAnimEntryBuildKeyMatrix` exactly (leftovers revisit 13, not matched). Related finding there: an f32 parameter read only as `*(f32 *)&arg1` (K&R `u32 arg1`) is address-taken and never a colour candidate, so the target's `mov.s $f14,$f4` weight copy (a coloured split piece of the parameter) needs a real `f32` parameter with an ANSI prototype; the caller's `lw a1` load is unchanged by the prototype. Two FP locals with equal adjsave colour by first mention: a dead early `c7 = 0;` gave c7 the lower bit and swapped $f12/$f18.
