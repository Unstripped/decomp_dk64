From `lightSampleColorAtPosition` (leftovers revisit 13, draft 94 -> 42, not matched): (1) a value that crosses one call inside a loop costs 10 to save plus 10 to restore in a caller-saved register, while the first use of an unused callee-saved register costs `firstUseCost = curstaticno * 0.25` (ties go to caller-saved). The target's deltas in caller-saved $f2/$f14/$f16 therefore imply at least 80 CFG nodes where natural C had 42; each `if (1) {}` adds 2 neutral nodes without touching any live range (FAKE pads; find the natural structure before keeping them). A later range takes a callee-saved register at zero cost only once a non-interfering range already used it ((f32)arg3 lands in $f20 only after dy/dist took it). (2) `uoptcopy.c` `find_replacements` refuses to copy-propagate a variable into a multiply whose other operand is an expression (`no_nested_ops`): a variable computed in one block and used in a later block as `entry->unk14 * nz` stays a variable load, which uncoloured gives the target's store-then-reload; the same use in the same block is substituted at input instead. A `goto lbl; lbl:` boundary splits the block without adding length to ranges through it. (3) Splitting an update into two statements (`dot -= a; dot *= b;`, `m = (1/u)/3.0f; m -= range;`) adds references (dot 35 -> 40, winning a tie by bit order) and computes the intermediate in the variable's own register (`sub.s $f0,$f0,$f2`); the second fixed a whole case's FP scratch order (full 65 -> 42).
