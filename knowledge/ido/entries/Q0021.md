spimdisasm treats a float symbol spanning several non-zero words (bonus `D_8002DDD4`, `0.05f, 0.45f, 0.45f`) as a const array and emits it as a standalone `.rodata` file instead of migrating it into its function's `.late_rodata`, which moves the object's `.late_rodata` by its size. Fix: `D_8002DDD4 = 0x8002DDD4; // segment:bonus force_migration:True function_owner:func_8002A398`.
