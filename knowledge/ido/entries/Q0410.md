a constant-trip loop of 5 or 6 peels iteration 0 and unrolls the rest off one unfolded base pointer (count 4 folds fully), so an asm "store chain" with `li a2,1; sll/subu` is such a loop; only the last loop in a function unrolls. A countdown loop keeps its `bltzl` entry guard only as `i = N;` before an unrelated `if`, then `while (--i >= 0 && ...)`. `i < 0x2AU` drops a dead `or` after the loop-var store.
