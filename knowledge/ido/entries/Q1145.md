Using the rounding loop's exit value of `d` for real (`d += '0'` as the first digit's init) keeps d live like Q1105's dead `if (d) {}` and recovers the register order (190 -> 88 lines), but the digit is then built with `addiu` instead of the target's `li` at 0xbc4, so the dead test stays the only full match.

**2026-11-17 extension (Hackvsprintf8, ledger fe8bc4e3):** the target rounding loop exits with `beqz v0,0xab4` at 0xa80 whose delay slot `addiu v0,v0,-4` (0xa84) clobbers d on the exit path, so d is dead after the loop and no real read of d can match; the e-arm trio (69d5aa, e415e5, 7dcd26) provides a code-free v0 range confined to the zero-pad block (keeps `slt v1,a1,t0` at 0xb9c off v0 while fneg2 != 0 holds v0 0xabc-0xb4c).
