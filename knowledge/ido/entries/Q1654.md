A `switch` that replaces an `x == A || x == B || x == C` test with ascending case values emits the same compares in the same order and adds cfe's switch-selector temp below every block home. That is a natural source for the one frame word a block pad gave. renderModelAnimatedSlot site 1a2082: compares 0x55c8/0x55d0/0x55d8; the cfe temp sits at -244, after the PopMatrix `_g` at -240. Case values written out of source order are re-sorted (score 11).
