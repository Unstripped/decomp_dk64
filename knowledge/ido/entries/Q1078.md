Same unit, textBlitGlyph (pointer arithmetic, see Q0540/Q0464/Q0813): retyping an integer address parameter to its real pointer type removes a `(u32)` widening hack: in `bool + ptr + u8` the u8 takes its own index conversion, so the loop bound keeps a separate int widening (andi t3,a0,0xff / move a0,t3).
