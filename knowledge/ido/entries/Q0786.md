Limits of the ARRAY_COUNT bound local (Q0780): it does nothing for a folded range check `(u32)index < N` (`sltiu`), where a constant held in a temp is a candidate-order steer (Q0214) and stays tagged; and a u16 table ending in 0x0000 at a 4-byte boundary does not prove its element count, so it cannot justify the idiom. It does hold for a struct-member array bound, where the old narrow (s8) counter width (Q0257) stops mattering once the bound comes from sizeof.

Evidence: six tables incl. the struct-member array unk42[14] in global/FCCD0.c; the range check in global/F56F0.c keeps its tag (director).
