actorSub140TransformTriangles (global/70FD0.c) hoists -1 into $s7 (`li s7,-1`). The target compares with `bne s7,v0`. `boneOffset == -1`, `-1 == boneOffset`, `(s32)boneOffset == -1` and `== 0xFFFFFFFF` each differ only in that operand order; only the tagged `(boneOffset ^ 0) == -1` matches (trace_actorSub140TransformTriangles.txt).
