In `textFontAgeSheets`, computing the index once into a named local (`sheet = n - 1;`) and using it in both array accesses produced the target's `addu` operand order, where repeating `n - 1` inline swapped base and offset. Try a named index before a steer when only the operand order of an indexed load differs (cleanup round 10).
