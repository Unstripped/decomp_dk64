IDO loads `&D_8004A78C` once for `D_8004A78C`/`D_8004A790`; when the asm uses two separate `lui`/`%lo` pairs, declare them as one array (`extern s32 D_8004A78C[]`, `[0]`/`[1]`). Conversely when the asm uses an offset symbol (splat's `D_8004BCD4` = `D_8004BCD0 + 4`), access through that symbol to reproduce `%lo(D_8004BCD4)`.
