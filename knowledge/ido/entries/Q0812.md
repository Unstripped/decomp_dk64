In a function declared non-void whose source falls off the end, writing the last call as `return f(...)` makes the call's `v0` the function's return value, so a value reloaded after the call is placed in `v1`. That can replace narrowed-temp steers that only moved a value out of `v0`.

Evidence: effectCreateAtActorBone (global/119370.c): `return effectCreate(...)` pushes the later reloaded actor pointer into v1; the plain flag test then matches (9f69ab fixed; actor param void * -> Actor *, 8 callers unchanged).
