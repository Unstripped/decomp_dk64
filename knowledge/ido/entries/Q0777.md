When consecutive vertex (or record) writes need a uopt block boundary between them (Q0557), write each element through a pointer and step it after the element's stores (`vp->x = ..; vp->y = ..; vp++;`): the pointer steps give the same live-range sharing as a dead test between the stores, with no dead block.

Evidence: textObjectDrawFlat/textObjectDrawRotated (global/100180.c, FAKE 2 -> 0): the dead test only added one block (28 vs 27; without it 8 register renames). textDrawStringVtx (FAKE 7 -> 5): the per-vertex walk, each vertex storing all its fields then `vp++`, replaced both the block-splitting dead test and the four trailing `vp++` steer (ae146d, d481a0).
