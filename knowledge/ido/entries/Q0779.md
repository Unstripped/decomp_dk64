When a caller loads argument registers right before a `jal` to a callee whose definition takes fewer parameters and stores no homes for them, the original called through a K&R (unprototyped) declaration or definition. A K&R definition in the callee's file (`s32 f(slot) s32 slot; {`) reproduces the calls with no block-scope redeclaration.

Evidence: slotQueueStateFadeIn (global/FCCD0.c) calling slotQueueGetCountStep, now defined `s32 slotQueueGetCountStep(slot) s32 slot; {` (director-accepted).
