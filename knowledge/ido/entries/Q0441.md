visible in `cc -S` (pre-as1); it counts instructions as1 later deletes (redundant `sll`/`sra`, doubled `andi`, u64 no-op `move`/`li` triples) and excludes every `$t` register uopt uses as a web anywhere in the function. A one-off skip in the final asm is a deleted instruction or a missing web: fix the source that emits it (true callee widths, no explicit `(u8)` inside a masking gbi macro), or add a web (`cnt = command; command ^= 0;`). Picks are least-recently-used among free temps (initial order t6..t9, t0..t5); rescaled address arithmetic (`&arr[i*4]` on 16-byte elements, `arr + (i << 2)`) and no-op `& 0xFFFF`/`& 0xFF` on narrow stores touch a temp without code.
