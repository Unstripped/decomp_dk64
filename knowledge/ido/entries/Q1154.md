jetpac/0 jetpacUpdateStateAndInput: when uopt copy-propagates a local's constant into a store to an extern global, the store becomes a direct symbol store (ustr S) and leaves the global's address web (one use, uncoloured); a literal store keeps uistr(lda), so the address gets a register. A store-only value-named constant local steer can be replaced by `T *p = &G;` used for all accesses (0x1168/0x11a8).
