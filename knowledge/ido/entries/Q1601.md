Extends Q1587 and the Q1172 correction. sfxUpdateLevelAmbient (global/7130.c) site 82ceb0: `angle` (bit 127) is one candidate for three roles (emitter angle, group pan, rain-block listener angle); together adjsave 8.87, the first callee-saved FP user ($f20). Split: the group pan alone (20.0) colours before any callee-saved FP register is in use, when a callee-saved register still costs its full first use, so uopt picks caller-saved $f12 and spills it around the post-event call (582); emitter + group pan (9.69) take $f16; emitter + rain (2.33) go to memory. Only the three-role sum gets $f20. The rain listener angle is part of the merged range too (Q1587 named only the group pan). Q1586's per-block pointer does not transfer (566/674 split, 209 base).
