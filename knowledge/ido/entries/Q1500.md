Extends Q0954 (an after-switch block for a goto-shared case body reorders the case bodies) and confirms Q0591 (gotos into a shared tail are usually original source). Moving a shared case tail after the switch, with the other arms `continue` and the tail's users `break` into it, moves the tail's code behind the last case and merges the per-arm exits, so it does not replace the shared tail.

Evidence: boot/3D20.c vsprintf (unit Cleanvsprintfc, merge 4e290fff): the `_itoa` call moves from 0x700 to 0x1148 (score 429); moving the fetch chain too gives 500.
