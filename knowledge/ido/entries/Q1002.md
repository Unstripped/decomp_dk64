At IDO 5.3 -O2 the `register` keyword is not a colouring lever: it neither changes a local's candidate bit order nor gives it a register ahead of an earlier-appearing candidate.

Evidence: gfxSwapGeometryModeCullBits (global/17B90.c): `register s32 op` without `op = 0` up front scores 15, the same as removing `op = 0`; w0 still colours first (Q0897).
