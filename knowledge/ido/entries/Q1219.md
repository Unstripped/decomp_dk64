When both arms of a branch call a function with the same constant argument, IDO hoists `li aN,K` above the branch and m2c pins it to whatever local lives in aN, writing a redundant `local = K;` (bonus/0 bonusControllerUpdate 0x610 `li a2,1`, endOnTrigger already 1 from the loop head at 0.c:187). Such statements are codegen-neutral (fdiff 0) and can be deleted.
