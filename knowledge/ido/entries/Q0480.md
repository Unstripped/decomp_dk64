a store through a local pointer (`e->f = v`, `p = &G[i]; p->f = v`) kills same-typed scalar-global candidates (forcing reloads); the same store through the named array (`G[i].f = v`) does not. A store to a scalar global in a loop makes an `s16 *` global table reload each iteration; a distinct struct pointer type avoids it.
