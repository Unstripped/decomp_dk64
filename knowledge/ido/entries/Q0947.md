In `hudPauseMenuUpdate` (global/ACDC0.c, carve #6 of unit HackhudPauseMenuUpdate2, merged 4defc785 together with C1E70 on base 108db654) the fake count went from 1 to 0 when `extern s8 sPauseSaveCooldown` became `static s8 sPauseSaveCooldown = 0;` inside the function. As a function-local static, uopt keeps it as a native variable with its own `lui`/`%lo` pair for each access (Q0761), so the dead entry read that had been splitting its address web was no longer needed. A C static gives the object a .data section (16-aligned and padded), so the whole TU's data had to move into C (0x807504E0-0x80750600). The order was the 20 file-scope tables first, then the statics of `hudPauseMenuUpdate`, `hudPauseMenuBuildPage` and `hudDrawTwoOptionMenu`, in function order. Both this file and C1E70 follow the source order of definitions. The tables come first here only because ACDC0 defines them above its functions. In C1E70, `D_807506B8` is defined after `actorNodeRingUpdate`, so it lands after that function's statics. Other TUs used interior splat labels (D_80750531, D_807505AE, D_807505B2), so those went to undefined_syms.us.txt. Unit "2026-11-15: cleanup HackhudPauseMenuUpdate2".
