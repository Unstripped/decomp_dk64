heapReleasePool (global/15050.c, site 5aefb1): when two exits reach the same `return 0`, uopt hoists `move v0,zero` into the entry block and the second exit becomes `bnez; nop`. An empty block on one path keeps `v0 = 0` in the return block, so as1 emits `bnezl ...; move v0,zero` as in the target.
