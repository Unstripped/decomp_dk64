naming array elements in locals inside a binary-search loop (`u32 v = tbl[mid];`) forces a saved register and a stack frame; using `tbl[mid]` directly in the comparisons keeps it frameless. `low = 0; while (low <= high)` compiles to a single `bltz high` entry test (`actorTableBinarySearch`).
