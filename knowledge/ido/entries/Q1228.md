IDO emits a TU's .data with sh_addralign 16 and pads its size to 16. A function-local static at an unaligned address therefore needs the file's C .data to start at the nearest 16-aligned label before it: the arcade 0x26790 carve defines 0xB0 bytes in C (D_8004A790..D_8004A82C) so that arcadeDrawHud's sFrameCount lands at 0x8004A83C.
