EXTENDS Q1200 (see Q1055, Q0739, the 36880 compute_save entry): a reused loop counter can hold v0 over a later one-block use that emits no v-register instruction of its own (andi t9 at 0x1dbc) and, by interfering with a pointer local there, forces the pointer to v1 (0x1dd8-0x1e08); a dedicated index local used only in that block scores (1 load + 1 store)/1 = 2.0 < the pointer's 5.0, is coloured after it, and the pointer takes v0 (25). The steer retires only if some caller-saved integer variable with priority above the pointer's is naturally live in that block.
