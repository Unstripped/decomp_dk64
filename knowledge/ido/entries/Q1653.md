This extends Q1421/Q1148. A local defined as `x + 1` stays a uopt variable and gets a register (v1) when x is written as field-reading expressions instead of a local. uopt still CSEs it with an earlier identical expression (one div). With a quotient local (`loops = quot + 1`) it is copy-propagated into a one-block ugen temp (t5). Tested directly without a local, it is also a ugen temp.

Before tagging a dead second-use guard on an `x + 1` test, drop the quotient local and write its field reads inline at each use. pathPlaybackAdvance +0x35C/+0x384/+0x3DC/+0x430: the dead guard went (FAKE 1 -> 0).
