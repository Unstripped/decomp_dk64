A local assigned from an already-CSE'd load (`w0 = cmdStart->words.w0` after `command = cmdStart->words.w0 >> 24`) is a candidate live bb2..bb4 at colouring time and takes a register ($a2), but after colouring its reads are served from the load's register ($v1, `nor t6,v1,zero` at 0x270 in global/17B90 gfxSwapGeometryModeCullBits), so the copy emits no code. An unused register in the target can be such a phantom (it replaced a dead `if (command && command) {}` that held $a2). Colouring is bit-order "assigned (unconstrained)": a candidate's register depends only on which earlier-bit candidates it interferes with.
