In hudPauseMenuRender (global/ACDC0.c) a pointer parameter that is advanced and then returned is homed in its own argument slot (0x1A0(sp)), never in a local slot; a target that keeps the advanced pointer in a local slot (0x140) therefore had a separate local holding it while the parameter went on as the cursor (dl/list role-swap measurement, 12 lines without the dead test). For an array-of-struct entry address `it + j`, `j + it` and `&it[j]` put the index first in the add (addu v0,t7,s2 at 0x12f8); only `(u8 *)it + j * size` puts the base first (Q0488). A dead test at the end of the function also recoloured case 2's `cnt` (t0 vs v1 at 0x1d44): its effect reaches several blocks away (Q0583).
