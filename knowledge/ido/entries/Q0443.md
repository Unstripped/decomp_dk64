priority is adjsave summed over occurrences; unconstrained candidates colour in first-appearance order. Free levers: split one update into several statements (`k += 1; k += 1;` still one `addiu`), dead single-term compares (`if (v == v) {}`, `if (p->f == 0) {}`: no code, +adjsave; multi-term `v && v` leaves a real FP compare), a new dead local with a real assignment and a dead use, re-assigning a pointer to kill a web. A dead `if` that survives uopt leaves a label as1 treats as a block boundary, so it can break a schedule. `uopt_trace.sh -l 5`/`-l 6` tables (adjsave, con/unc, candidate numbers 1=v0, 2=v1, 3..6=a0..a3, 7..13=t0..t6, 14..=s0; FP 25=f2, 26=f12, ...) beat blind sweeps.
