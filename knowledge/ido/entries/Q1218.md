A store through a different pointer variable kills field loads through the other pointer regardless of type, both globally and inside a block (jetpacUpdatePlayerMovement variants A1/A1m/A1s fdiff 0); routing every access through one pointer behaves like the plain body. A second pointer to the same object chosen for this effect is a steer (tagged FAKE ba285d).
