The inverse of Q0601. In global/70FD0 modelSlotUpdateFacingTrigger an m2c local copied from a field (`actorYaw = gCurrentActor->yaw`) needed four steers. With the field read inline, the forwarded expression contains a memory load used once in its block, so uopt keeps the variable's store (Q0558) and the shared field load takes the register the local had. One rewrite retired a no-code redefinition kill (Q0499), two dead uses raising adjsave (Q0722) and a dead-store kill (FAKE 5 -> 1). Evidence: 0x3bf4 `lh a1,0xe6(t8)`, 0x3bf8 `subu a0,v1,a1`, sign test on t1 with `move a0,t1`.
