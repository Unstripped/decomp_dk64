The Q0922 signature (a separate `lui`/`%lo` pair at every access) holds only for a function-local static SCALAR. A function-local static ARRAY accessed at a constant index (`static s32 X[2]`, `X[0]`) still builds one base-address web. Corollary: an 8-byte symbol size at a TU's `.bss` tail can be section rounding (`.bss` is 16-aligned), not a 2-element array.

Evidence: audioBuildTask (global/6710.c): the static array emits `lui v1,%hi(.bss); addiu v1,v1,%lo(.bss+0x3098)` (+16 text); the 8-byte size comes from rounding 0x309c -> 0x30a0.
