In zoneFindBestReachablePoint (global/1295B0.c) `(d = X, d < best)` becomes `(d = X) < best` with fdiff 0: the target computes each distance only inside its short-circuit arm (0x1758-0x17F8). Q0282's case fails only because its test reads a different value than the one assigned. An assignment inside a short-circuit test whose value the target then uses is ordinary C (director ruling, ladder.md).
