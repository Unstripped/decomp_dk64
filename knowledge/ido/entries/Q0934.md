actorCollisionResolveSurfaceHit (global/7BBD0.c, 932d5d; FAKE 3 -> 2, merge 574a9a29, ledger ca866056, base e1a3636c): a counted `for (i = 0; i < 3; i++)` writing `&triX[i]`, `&triY[i]`, `&triZ[i]` compiles to a pointer walk whose end test stops at the START of the next local array in the frame (`bne s1,t4` with `addiu t4,sp,200` rebuilt each pass, 0x9f0-0xa24). Q0630 only covered a walk ending at the next global; the same LFTR lands on a neighbouring stack array. Leftover walker locals declared but unused each add a frame word (0x138 -> 0x148), and where `i` is declared changes the code (it takes the old pTriZ slot). With the walker as induction variable, `pTriZ != &triZ[3]` is rewritten as `pTriZ - 12 != triZ` (two address adds, 75 lines) while `<` keeps one address load (Q0489).
