Hackvsprintf11 (merge 13dc7afc), boot/3D20 vsprintf: the store of the single-use hundreds digit written through the tagged `PUTC` do-while(0) macro, `PUTC(exp / 100 + '0');`, matches (fdiff 0) where the old `d = exp / 100 + '0'; *buf = d; count++; buf++; if (d) {}` needed a dead read (7dcd26#2, retired). The macro's no-code blocks keep the quotient a uopt value in v0 (0xd00 mflo v0 / addiu v0,v0,48 / sb v0); with neither the macro nor the dead read uopt copy-propagates it into a ugen temp (mflo t8 / addiu t6,t8,48), 67 (Q1062). Limit: the blocks do not stand in for a dead test whose effect comes from READING a variable: `PUTC(padChar)` in place of `if (padChar == 0) {}` (e415e5) scores 42, the same as removing the test.
