A splat label that falls inside another object can be the following table indexed with a constant bias, not a member of the object it lands in. IDO folds the constant index offset into the address (`lui`/`lb %lo(D_80752DF0 - 0xA2)`), so the access names an address before the table and splat labels it. Writing the table with the biased index is relocation-equivalent. Related Q0264 (a table end named as the next symbol), Q0996.

Evidence (unit Polishglobal17B90b, merge 73811348):
- global/F56F0.c playerWeaponInitCrosshair: `D_80752D4E` (inside EFDC0's gPlayerStateCallbacks) is `D_80752DF0[animId - 0xA2]`.
- global/135D30.c func_8073195C: `D_80755F4C` is `D_80755F50[index - 1]`.
