In IDO 5.3, fake pointer arithmetic like '(s32)((s16 *)4 + n * 2)' used to steer ugen/uopt indexing trees can be replaced with natural type arithmetic '(n * 2 + 2) * sizeof(s16)'. Both compile to identical constant folding and register assignments for heapAlloc calls without convoluted pointer casts.
