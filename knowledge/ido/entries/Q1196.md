In global/42630 csCmdExec the target keeps the s16 parameter `csId` in its home and reloads it every loop iteration (sw a2,208(sp) / lh t5,210(sp) at 0x3694); the code keeps that only with the tagged `void *dm = &csId;` escape (FAKE 4f1968). Writing `*&csId` in the 0x2D compare instead is folded by cfe back to plain `csId`: the parameter stops being memory-resident and is hoisted out of the 0x3678 loop (full=548, the same as replacing `dm` with a pad). Extends Q1183: neither a codeless `&param;` nor `*&param` at a use replaces a real address escape.
