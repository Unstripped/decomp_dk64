EXTENDS Q1112/Q0995 (uopt copy propagation / regalloc; see also Q0922, Q1125, Q0761): a local holding the same index in both arms of an if/else stays live in the else arm when it is set from a function-local static (`slot = S >> 2`). The static's store-back stops copy propagation, so the local clashes with the static (v1) and pushes the arm's other local to $t1. With an extern plus a local copy (`v = G + 1; ...; slot = v >> 2`), uopt copy-propagates `v >> 2` and the local leaves the arm. In the pre-carve body an early dead read and an uninitialised else-arm dead read stood in for that liveness (target $t0 at 0x6648-0x66c0, $t1 at 0x6734-0x6798). 2. EXTENDS Q0395/Q0913 (cfe data layout; see also Q1228, Q0947): in IDO .data every initialised object starts on a 4-byte boundary and none is raised to 8. Evidence: s16/u8 scalars are followed by the next object at +4; the 5-byte CsPat5 at 0x807482E0 is followed by CsPat3 at 0xE8, and the 3-byte CsPat3 by CsPat4 at 0xEC; a static s8 is followed by an object at +4; f32[3] sits at 0x8074828C (4 mod 8). So a byte label at an offset that is not a multiple of 4 is always a split label (here D_807480EF -> D_807480EC[3]; D_80748212/D_807481F6 -> &D_807481F4[15]/[1]).
