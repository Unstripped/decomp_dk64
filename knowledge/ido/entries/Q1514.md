An empty `default:` that only adds a block (Q0908's block-split class) can be replaced by giving a competing variable a second definition in the same block. Each def and use counts in adjsave (Q1049, Q1257), so the extra definition raises that variable's priority, and it is coloured before the other range splits, which reproduces the effect of the extra block. Related Q1327 (the uopt split() rule).

Evidence: global/15050.c loadOverlay (unit CleanloadOverlay, merge 6baa6771): `size = X; size -= vram;` raises size's adjsave from 0.333 to 0.667, ahead of vram's 0.400. size is then coloured before vram's range splits, and vram's t3 piece stops at the preheader (`sw t3,232(sp)` at 0x1ec), as it does with the extra block.
