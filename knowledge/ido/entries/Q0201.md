a ternary (`x = c ? 1 : 3;`) or a provably redundant else arm (`else { v = 0; }`) keeps a `ujp`, so the previous arm ends in `b L` to the next instruction and the skipping branch becomes `beqz` + `nop`; self-assignment does not work (`func_806E7DF4`, `func_806DDAB0`, `func_806D2E9C`).

A dead abs arm `if (x > 0.0f) x = x; else x = -x;` and the ternary `x = x > 0.0f ? x : -x;` compile identically (both keep the `ujp`), so the ternary is the readable spelling (`playerStateBounceRecover`).
