an unprototyped callee (or one declared only inside a `#ifdef NON_MATCHING` park) shifts `$v0`/`$t0` for values reloaded after the call, and an f32 argument shows as `cvt.d.s` + `sdc1 0x10(sp)` with 8 more bytes of frame. Check every callee has a prototype visible to the matching build before register work.
