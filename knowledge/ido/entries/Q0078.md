IDO pads every object's `.rodata` to 16 bytes, so unreferenced zero bytes that reach a 16-byte boundary in the middle of one splat file end a translation unit. splat's `699B0` was three objects (`699B0`/`69E60`/`6AD90`, pads at `0x15DB28` and `0x15DBB8`); agents saw "code matches, rodata shifted by 8" (`func_80664D20`, `func_80665FB4`) until the file was split. `tools/rodata_owners.py` flags these pads.
