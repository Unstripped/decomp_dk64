cfe lowers `x.f = !x.f` on a u8 field through a hidden temp local (the uequ is stored to an isvar), which can be coloured into an argument register. `x.f = x.f == 0` has no temp: uequ{ucvt(uilod)} keeps the load in a t-register. So a dead `if (f == 0) {}` can stand in for a real `!f`. In arcade/0 arcadeUpdateBouncingBarrel, 571f64 (two sites) was fixed with `!facing` at both flips, where the temp takes a0 (`lbu a0,26(v1)` at 0x9aa8/0x9e10).

An early return (`if (gArcadeFrozen) return;`) instead of a whole-body `if (gArcadeFrozen == 0) { ... }` wrapper changes block structure: with the early return the entity pointer takes v1, and with the wrapper it takes s0. Lead ruling: early returns, the `!x` toggle and entity-first comparisons (both orders full=0) are ordinary C.
