Loading an s16 array element into a named s32 local before an equality compare (`current = arr[ch]; if (x == current && ...)`) makes the load a variable candidate with its own register; writing the compare inline (`x == arr[ch]`) loads into ring temporaries instead and renumbers every later temp. Such a local is source, not a steer.

Evidence: sfxAllocateChannel (global/7130.c): the local gives `lh v1,0(a3)` at 0x6a0 as in the target; the inline form uses t8 and shifts the later temps.
