In IDO 5.3, uopt automatically performs loop-test replacement (LFTR), transforming an array induction variable in loops like `for (i = 0; i < N; i++)` into pointer comparisons against the array end pointer (`sltu at, a1, a2`), eliminating the scalar loop counter. Past decomp matches blocked this with no-code or no-op arithmetic such as `(i ^ 0) < N`. Casting a signed index to unsigned in the loop condition `(u32)i < N` naturally blocks LFTR because uopt cannot prove pointer equivalence across signed/unsigned overflow boundaries, preserving the direct scalar index test (`sltiu at, v0, N`) without any fake arithmetic hacks.
