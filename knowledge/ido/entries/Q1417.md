EXTENDS Q1049/Q0900 with uopt's compute_save formula (uoptreg2.c): adjsave = sum((loads + stores) * freq) / bucket(live units + reaching blocks), bucket(n) = n for n <= 2 else ((n - 2) >> 2) + 2; an exact tie goes to the lower candidate bit. A copy live in two blocks with 4 points (2.0) loses to a one-block shared load with 2 uses (3.0); reusing it for an unrelated count gives 6/2 = 3.0.
