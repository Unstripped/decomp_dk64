an `s16` vs `s32` return in a callee prototype (`mathAngleBetweenPoints2D`, `func_80672A70`) changes caller temp registers even when the result goes into an `s16`; a `u8` return removes `andi`/`sb`. A call showing `sll`/`sra` of a constant means the callee has an `s16` parameter. Try return/param widths first on a register-only near-miss.
