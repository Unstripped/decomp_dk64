The same-quantity read (bossMainStep case 6) only helps when the target keeps the value in the local's register across a test or a read-modify-write (0x1dcc). In playerStateSurfaceTreadWater, reading the buoyancy through `target` in the default arm only to pass it to a call changes no code (the target loads it straight into $f12 at 0x7c68): uopt folds it into the argument, no reference is counted, and the split stays at 5-7 lines.
