Besides suppressing the unroller (Q0793), a later definition of a counted loop's variable inside the same block after the loop keeps the loop test as `slti at,s0,5` + `bnezl` (hudPauseMenuBuildPage, target 0x2a4c); without one uopt rewrites it to `li at,5` + `bne(l) s0,at`. A definition after the merge point (at the case `break`) does not count. Look for a real later use first: here `i = idx` holding the world row (the sibling block's role, Q0846) replaced a dead `i = 0`.
