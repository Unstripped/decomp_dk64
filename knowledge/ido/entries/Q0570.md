In IDO 5.3, an empty dead 'if (field == 0) {}' inside an outer switch case can be an artifact of an inner switch. Replacing the empty guard with an inner 'switch (field) { case 0: break; }' matches sibling cases and emits identical branch/jump-table control flow without dead test FAKEs.
