In `bossArmydilloStep` (boss/0), a block-scoped `s16 val = state17C->cannonAngA;` copy existed only to own a frame word. Reading the field directly gives the same instructions, but every home after it moves 4 bytes (0x48 -> 0x4c, 0x40 -> 0x44). An unused function-scope pad word (`pad_bot[2]`) restores the layout, so the copy goes: fdiff 0 (the permuter hinted it with an unused int).
