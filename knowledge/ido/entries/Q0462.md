uopt hoists a loop's `i = 0` to the earliest join (above a `jal`) when `i` spans an earlier block with no other store in between. A dead store `i = 4;` right before `for (i = 0; ...)`, or a fully unrolled constant-trip init loop (`for (i = 0; i < 4; i++) a[i] = 0;`, recognisable from unrolled store order [1][2][3][0]) that leaves a dead `i = 4`, blocks it (`actorSagWaveUpdate` 815 insns, `sfxUpdateLevelAmbient` 1375). `for (i = 0; i < 3; i++)` vs `do {} while (i != 3)` moves the `i = 0` past hoisted `ldc1`s (closed the triangle tests).
