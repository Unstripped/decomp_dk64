`s32 sel = D_807FBB40->unk154; ... switch (sel)` reproduces the target's per-path `lbu a0,0x154(..); b; move v1,a0` tails: uopt PRE re-inserts the load on each path that killed it, so ONE source assignment yields many reloads. A `u8 sel` loads straight into `v1` and swaps the hoisted `&D_807FBB70`/`&D_807FDC90` registers; writing the reload in every case grows the frame (`func_806AFB58`, `func_806B2D64`, `func_806B2790`).
