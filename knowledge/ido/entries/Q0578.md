In `actorCollisionResolveSurfaceHit`, a stack-passed u8 parameter `flag` is tested twice around calls. With `if (*(u8 *)&flag != 0)` both tests reload the byte with `lbu` from the stack home, as the target does; with a plain `if (flag != 0)` uopt CSEs the two stack-parameter reads into s1 (a ucvt{flag} candidate), so the plain form does not match at the current base. One address-taken read in either test is enough (Q0817).

Corrected 2026-11-14 (HackactorCollisionResolveSurfaceHit): this entry previously claimed the plain `flag != 0` test compiles identically; it does not.
