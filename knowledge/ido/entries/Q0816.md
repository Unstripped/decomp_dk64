With a typed pointer `T *p`, the field access built on the add decides the addu order: `p[i].f` builds idx*size + base, while `(p + i)->f` and `(&p[0] + i)->f` build base + idx*size, which decides which register keeps the induction value. A bare address `p + i` behaves like `&p[i]` (Q0813); only inside a member access do the forms differ.
