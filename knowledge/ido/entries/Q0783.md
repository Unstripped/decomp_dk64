When every read, increment and store of a scalar global goes through one pointer local (`T *p = &G;`), uopt promotes the global into a register (an isvar candidate), and a constant stored to it (`*p = -1`) is built in that register (`li v0,-1`). Mixing in one direct `G = ...` store keeps the constant block-local. The promotion can also reorder ugen's region-entry load against a coloured table address: identical instructions with a different relocation-table order (fdiff TEXT OK / RELOC-EQUIV; the ROM hash decides).

Evidence: actorNodeRingUpdate (merge 9c5f348b), director-accepted.
