`if (p != end) do { ...; p++; if (p == end) break; } while (1);` stops the 2x unroll of a pointer loop; `if ((bound = count) != 0) do { ... } while (++i < (u32)bound);` keeps the bound in `a0` (frame -8); a `while (s->x == 0 && G != 0)` loop keeps its entry guard only when `G = 1;` precedes it (a local `result = 1` folds the guard); `for (i = 0; i < 14; i++) a[i] = 0;` peels a 2-store remainder with direct `%lo(a)(at)` stores, explicit stores hoist `&a`. A guarded `if (n > 0) do { ... } while (k < n);` compiles the same as `for (k = 0, n = count; k < n; k++)`. The bound copy `n` is load-bearing: writing `k < count` recolours count from s1 to s3 (`sfxUpdateLevelAmbient`, 7130; kept as a tagged FAKE).
