`arg1--; while (arg1 != 0) { arg1--; node = node->next; }` triggers IDO's modulo-4 loop unrolling with remainder loop peeling, maintaining `$a2` for the decrement counter and `$a1` for the pointer (`actorStepSubNodeList`).
