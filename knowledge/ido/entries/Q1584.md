450.c mapLoadLevel: `camInit(loadedAsset = assetLoad(...))` emits an extra `move a3,v0` (0x3448) before `move a0,v0`; the two-statement form (assign, then pass the local) drops it (fdiff 1), so the assignment-in-argument whose value the target uses is ordinary C. Related (7CA80 actorInit): `off + (s32)p` and `off + (u8 *)p` give the same offset-first addu (Q0813) but the byte-pointer form moves the address of the just-stored global from a2 to a1 (0xa4-0xac).
