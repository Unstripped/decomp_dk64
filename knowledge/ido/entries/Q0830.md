m2c output `if (n > 0) do { ...; i++; } while (i != n);` is IDO's own rotation of `for (i = 0; i < n; i++)`: the `for` spelling gives identical code, also with a compound exit (`sfxId == 0 && i >= 0`), while writing the `!=` in source does not reproduce it (full=1). Likewise a guarded `if (c) do { } while (c);` is interchangeable with `while (c) { }`. Write the plain loop (an explicit guard around a `for` adds its own test, Q0083). Q0364 records a function where a guarded do-while and the `for` differed in preheader naming, so measure the swap.

Evidence: measured 6 times in race/7BD0, 6650, 52B0 and 36B0 (merge de143679); the `while` form 6 more times in RereviewSmallFiles3 (merge cc138d52).
