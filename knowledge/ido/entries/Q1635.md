ACDC0 hudPauseMenuUpdate (extends Q1630): `credits = hubWorld == 8 && menuGetTimerFlag() != 0;` makes cfe evaluate the `&&` into its shared expression temp, -44vreg, the same temp both `switch (gCurrentMap)` and `switch (hud->page)` use (uopt -l 6: `ustr{-40vreg}{-44vreg}`, bit 245); uopt copy-propagates the named local (credits, bit 243, no coloured range). The map switch value, the page switch value and the flag therefore form one candidate coloured a1: `lb a1,18(s0)` 0x61c, `sltiu a1,a0,1` 0x814, `sltu a1,zero,v0` 0x82c. The hand expansion `credits = hubWorld == 8; if (credits) credits = ...` keeps the local as its own candidate (39) and needs the old shared `sel` local (FAKE c127b7 / db430c). With the `&&` form and plain `switch (gCurrentMap)` / `switch (hud->page)` both FAKEs go (whole-object fdiff 0): the target's a1 "sel" web is cfe's temp.
