Extends Q0804 (a u8 selector local gets its own promotion copy register, an s16 does not) and Q0428's 2026-11-18 correction (a narrow unsigned count's `move sA,sB` before the loop is cfe's int promotion): a u16 count reproduces the same separate promotion copy as a u8 (`move s3,s1` as the loop bound, score 0), while s32/s16 counts are coloured s3 directly with no copy (score 21). The copy comes from the unsigned narrow type, so retyping the u8 count to u16 is the same width steer: the u8 site (b41e92) stays tagged.
