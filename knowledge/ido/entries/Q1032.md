Moving a pointer load into the loop/if test, `(pb = G[slot])->active != 0` as the last `&&` term, places the pointer copy in the test block, so the body's first field load no longer interferes with the loaded-pointer web. It is a natural spelling of the block split a dead test after `pb = G[slot]` was providing.
