A local assigned on entry and reassigned later stays a register candidate live from function entry even after uopt removes the dead entry def, so it claims the cheapest free register early. A defensive declaration initialiser gives exactly that, and replaces hacks such as an unused early address calculation or a dead store in one arm that only coloured the variable early.

Evidence: raceGetRoute (race/A960.c, FAKE 3 -> 1): `T *e = NULL;` (the early-exit path returns NULL) replaced the unused early address calc; behaviourFairyInitPlayerScale (global/BDEE0.c): `s32 dir = 0;` replaced a dead store in one arm. Both director-accepted.
