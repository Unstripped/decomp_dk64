Storing a global load straight into a function-local static (`sPageAddr = (u32 *)gRdpOutputBuffer;`) and reading the static back (`sDumpBase = sPageAddr;`, `cur = sPageAddr;`) keeps the read a real reload (the stored value contains an ilod, Q0558) and uopt colours the loop-head load in $v0 (`lui v0` / `lw s5,%lo(sPageAddr)(v0)` at 0x1018-0x101c, Q0545) once the static's other uses are pointer arithmetic on the u8 * gRdpOutputBuffer. That plain scalar form replaced the one-element `static u32 *sPageAddr[1]` + page-copy steer, so Q1129 (neither a retyped static nor a pointer local replaces the second consumer) holds only for its measured body; the permuter found the shape (base 10 -> 0) and the match differs only in relocation-table order (fdiff --reloc-ok).
