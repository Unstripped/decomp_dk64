Passing an s16 local to an `Actor *` parameter through `(Actor *)id` makes IDO build a separate sign-extended word (`sll`/`sra` pair) and home it in its own stack slot (frame +8); passing it to an `s32` parameter does not, even with an explicit `(s32)` cast. So the callee's pointer parameter type shows in the caller's frame: call-site declaration evidence (Q0486).

Evidence: modelSlotBuildProxPaths (global/36880.c): `sll s2,a0,0x10` / `sra t6,s2,0x10` at 0x1584/0x1588, `sw t6,152(sp)` at 0x15c0, `lw a0,152(sp)` at 0x16b0/0x17c0; with an s32 owner the frame drops 0xD8 -> 0xD0 (38 diff rows).
