Not every code-free statement that mentions a variable is a use to uopt. Kept by cfe (x stays live exactly like `if (x) {}`): `x ? 0 : 0;`, `x && 0;`, `if (x);`, `if (x) {} else {}`. Dropped by cfe (no use): `(void)x;`, `x;`, `(void)(x != 0);`, `switch (x) {}`, `switch (x) { default: break; }`. A dead-use steer can only be respelled within the kept class.

Evidence: enemyAggroStateUpdate site 627052 (global/12E800.c); the `(void)x;`/`x;` drops were seen in slotQueueStateMoveToTarget (see Q0908).
