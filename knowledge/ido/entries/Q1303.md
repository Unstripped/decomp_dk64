File src/global/FCCD0.c, slotQueueDrawLabel f22aa7 + slotQueueStateMoveToTarget 34e891 (both kept). 1. cfe reuses its switch-selector temp for a later `?:` result in a case arm (see Q0944, Q0296, Q1133): a 2-case switch's selector temp is also the `%d` ternary result there (-68vreg in both stores), raising its priority to 3.0 so it takes the vararg register a2 and the selector is compared in a2; the `?:` value in a named s32 local gives the switch its own temp (1.5, v0) and the pointer v1, at one frame word. A selector landing in an argument register can come from temp sharing. 2. EXTENDS lever (c)/Q1092 (see Q0804, Q1053): a u8 switch-selector local carries a no-code u8 -> int convert candidate (cand 51, priority 1.5) that still takes a register (v1, pushing the pointer to a0); an s16 local converts on the store (no such candidate); s32 has none. 3. Frame layout: a u8 home at -13 followed by a pointer leaves -16..-14 free, usable only by a 1-2 byte local without shifting spill offsets; any int-width local appends a frame word (spill 0x30 -> 0x2c). Check this gap before calling an extra local a frame-word cost.
