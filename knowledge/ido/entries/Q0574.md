Named temporary variables for common cross-product expressions such as `N3 = (d02 * d6A - d68 * d04)` and `N3b = ...` can cause uopt to treat them as distinct web candidates that compete for register allocation and spill. Replacing both named temporaries with the identical inline expression `(d02 * d6A - d68 * d04)` allows uopt's global CSE pass to recognize the equivalence and assign the result to a single callee-saved FP register naturally, eliminating fake steering temporaries.
