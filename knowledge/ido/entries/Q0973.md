In launchBarrelUpdate (global/80150.c, kept state bd5eb8, unit "cleanup HacktagBarrelOrbitKongs2"), the dead `if (0) {}` was kept because of where uopt places its `.alias` reset. With the dead test, the reset `.alias $3,...` for the gActorGlobalState address is emitted at the case-1 entry. Without it, the reset comes right after `jal camStartPath`, and as1 then hoists `lui a1,0x3f80` from the next block above `bne v0,at`. The lui ends up at 0x364 when the target has it at 0x378, which gives full=2. An as1probe showed that inserting a `.alias` reset before `$38` is the only edit that brings the diff to 0. So the reset acts as a scheduling barrier for as1, and a C-level dead test can move it. This is the same function as Q0855, where a dead `if (sub) {}` controlled colouring instead. Here the dead test controls as1 scheduling.
