a single-def local used only later (at a call or in one `if` arm) is sunk past stores; assigning into an existing multi-def variable (`dx = dx * dx + dz * dz;`, `sp2E += ...`) or reusing a dead param/local (`if ((zero = x) >= 0x1F)`) pins it. A parameter the target modifies in place (`arg1 += 0x100`) gets its `move` at entry; a separate local copy moves it and takes a slot.
