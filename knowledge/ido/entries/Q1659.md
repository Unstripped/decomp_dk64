In loadOverlay (0x1b0-0x1c4), stores to gFramebuffers[0] and gFramebuffers[1] in one block written through the array make the shared base a uopt-coloured address constant (t1). That drops the two `lui at` the target emits. The splat split label for the second element (`D_80744474`) is a separate symbol with its own %hi, so the target code matches it. Folding the label into gFramebuffers[1] (`rename.py fold`) breaks the match (12 lines) and the label stays. Before folding a split array label, check that the target does not materialise each element's address separately.
