as1 does not move instructions across `.loc` boundaries at -O2 (a one-line `if (..) {..} else {..}` drops the else block's `.loc`: fixed one vsprintf hunk); it groups single-predecessor successors into extended basic blocks, so any record between `b $epilogue` and the next label changes hoists far downstream; it hoists a target's first instruction into an entry-block (bb0) load stall only when that label has one reference; it does not hoist fall-through instructions into a stall when their registers are live at the branch target (`.livereg` mask bit `31 - r`); a branch right after a load lets as1 put a fall-through op in the stall and turn the branch into a branch-likely (+1 insn). uopt emits block statements before block-end register loads (`rlodbb`, descending register number), and a `b` delay slot takes the last.
