Extra K&R call arguments that pin values to `$a2`/`$a3` can be compensating for a reused local: with the real prototype, the same registers come out once one local carries both values in sequence (`count = C - mid; count >>= 3;`). A separate local per role lets uopt place the values elsewhere.

Evidence: modelSlotReplaceSegment6Commands (global/36880.c): 4-argument K&R calls pinned seg to a2 and len to a3; under the shared 2-argument prototype the reused `count` reproduces them (0x4f90 `subu a3,t7,v1`, 0x4fac `lw a3,24(sp)`), while a separate `len` puts mid in v0 and C - B in a ugen temp.
