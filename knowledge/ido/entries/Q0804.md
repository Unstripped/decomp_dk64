A one-case `switch` on a u8 local promotes the selector to int in a separate copy register; on an s16 local the selector uses the local's register directly. Changing the local's width is a natural respelling that can replace a register steer.

Evidence: textBoxUpdateRows (global/A8400.c, FAKE 1 -> 0), director-accepted.
