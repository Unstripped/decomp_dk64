EXTENDS Q0770, REFINES Q0894/Q1057 (see Q0474, 17f queue Cleanvsprintf item 1): a local copy of a fetched byte decides the compare operand order. `c = *++f; if (c == '%')` compares an isvar, kept variable-first (`bne v1,a0`); testing the fetched byte itself everywhere (no copy) makes each compare work on `ucvt(*f)`, which uopt orders constant-first (`uequ{37}{1255}`, `bne a0,v1`); ucvt(*f) takes v0 (adjsave 73.5 -> 160.1), ilod(f) v1, 37 a0. The Q0894/Q1057 register race needs the copy live: drop the copy, not compare `*f` beside it.
