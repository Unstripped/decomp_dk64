For a float compare against an int-plus-float sum, used directly as a branch condition ugen emits the int operand's conversion (mtc1/cvt) before the float sum; as a statement value (`ret = a < sum`) the sum comes first. The target's FP instruction order therefore fixes which form the source used. In the statement form, only redefining an operand blocks the store forwarding of `ret`.

Evidence: spawnNodeActorOutOfRangeOrHidden (global/1295B0.c, 6a6ccf kept).
