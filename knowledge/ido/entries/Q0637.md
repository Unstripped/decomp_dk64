In 42630 the `effectSetDepth` proto-steer was attributed to `csCmdExec`, but its effect is in `csCmdSpawnSparkAndLight`: the local prototype gives `li a0,1` there where the shared u8 prototype gives `andi a0,s4,0xff`. Before diagnosing a file-scope proto steer, find which caller's code actually changes (diff the whole object, Q0626).
