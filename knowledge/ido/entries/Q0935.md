`actorCollisionResolveSurfaceHit` (src/global/7BBD0.c; 6AD90 unit, the function at 94c1f4, kept): the 8th parameter is a u8 passed on the stack. A plain `flag != 0` test adds a `ucvt{flag}` candidate (candidate 24, adjsave 0.75, live bb 2..11) and it gets coloured into an s-register. Spelling the test as `*(u8 *)&flag` removes that ucvt candidate and leaves only the uncoloured param variable (cand 22), so both tests reload `lbu 343(sp)`, as the target does. As a stand-in, retyping the parameter to s32/u32 scores 118 because the variable itself then colours (`lw s2,0x154(sp)`). This extends Q0494 (a narrow formal used at entry makes a dominating ucvt candidate) and Q0742 (a width change changes whether the range is coloured). The pun is a way to test a narrow formal without creating the conversion candidate. Unit: 2026-11-15 cleanup HackactorCollisionResolveSurfaceHit3.
