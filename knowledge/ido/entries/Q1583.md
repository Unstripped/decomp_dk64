CEAE0 playerUpdateCommon 318197: when several call arguments share one `&p[i].f` address, the identity cast `(PlayerStruct *)gPlayerSlots` or a pointer stored as element 0 of a global pointer array (`arr[0][i].f`) counts as a non-leaf base and gives base-first `addu`; a pointer that is a member of a global struct (offset 0 or 4) behaves like a plain pointer and gives index-first (minimal file: f_mem0/f_mem4 `addu v0,t7,t8`, f_arr0/f_cast `addu v0,t6,t8`). Removing the cast changes only cfe's lod position, and the 37 differing rows are ugen temp-ring renames (Q0717), not uopt colouring. Extends Q1533/Q1448.
