In camComputeEyeFocus (global/201B0.c, a9e334, fixed), a u8 global `G` was tested later as `if (G != 0) { if (G == 1) ... } else ...`. Rewriting it as `switch (G) { case 1: ...; break; case 0: ...; break; }` lets an earlier signed `G != 1` test keep a local `li at,1` + `beq` (0x7818; 0x7c80-0x7c88). Before the rewrite, matching that test needed the `1U` workaround, because the nested-if constant 1 joined a shared unsigned/typed constant web with the earlier test (Q0463, Q0843). The switch's case constants appear to form their own context, so the earlier compare's constant stays local. When a `1U` suffix is only there to stop a constant from being hoisted or shared, try changing a later nested equality chain on the same narrow global into a `switch` and drop the suffix. This was found during the HackcamComputeEyeFocus2 cleanup (merge d61261e2, record 5c7c3642). Also see guide ido-uopt-statics-and-live-ranges.
