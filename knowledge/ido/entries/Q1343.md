NEW, EXTENDS Q0992 (uopt candidate order / branch shape; see Q0994, Q0469): when a pointer field is null-tested and copied into a local, the position of the copy decides the candidate order and the branch shape. With `sub = p->f; if (p->f)`, the load candidate is numbered after the local and takes $v1, and `move v0,v1` goes into the beqz delay slot. With `if (p->f) { sub = p->f; }`, the load is numbered first and takes $v0, the copy comes after the branch, and the branch becomes beqzl with the epilogue `lw s0` in its slot. A single read (`sub = p->f; if (sub)`) never makes the copy: the load needs a second use while it is still available. Scores: plain 4, test-then-copy 16, re-read in body 12.
