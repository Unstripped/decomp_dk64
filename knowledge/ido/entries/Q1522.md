Tried in 201B0 camComputeEyeFocus as a goto-free form of its shared tails. The selector stays in a register across the first
switch's arms (`lbu v0,340(s1)` at 0x91cc where the target uses t6; `lbu v1,1(t1)` 0x8020 vs t7), and each arm's exit copies the
second range check's first instruction into its delay slot (`addiu t5,v0,-62`): +13 instructions for the state switch, +26 for the
path switch. The gotos stay (Q0591 shared tails).
