Writing a masked global flag out in each of two else-if conditions (`G & M` twice) is enough: uopt CSEs the `lw` + `andi` into one register across the conditions. An unrelated reused local that holds the masked value for both tests is therefore a removable steer.

Evidence: hudPauseMenuUpdate (global/ACDC0.c): with the flag written in both conditions the shared value is carried as in the target (`move v0,t7` at 0x8ac).
