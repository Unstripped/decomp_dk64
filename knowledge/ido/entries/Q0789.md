A local assigned a constant and then stored (`x = K; p->f = x;`) is copy-propagated: the constant goes into the store, the def dies and the constant is built in a ring temp. The variable keeps its own register only when the store is a join reached by several defs, or when uopt reads the assignment as an increment (`x += 2`, `(x & 0) + 2`); `x += 2` emits `addiu`, not `li`.

Evidence: audioBuildTask (global/6710.c, 8e31ef/#2 kept).
