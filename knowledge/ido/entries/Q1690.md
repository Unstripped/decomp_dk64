Two no-local spellings that cannot replace a reused local (census part 2 evidence; LeverScout29, 2026-11-25c): (1) a value written inline in a later operand of an `||` test is computed in that operand's own block, after the earlier compares; when the target computes it before the first compare (bossSpawnerUpdate: `sub.s $f0` at 0x3f4 ahead of `c.lt.d` at 0x3fc), the source had a separate statement for it (inline 147 lines, a dedicated dz local 21-23). (2) A struct field used as scratch storage (`f = err; f = v + f * k`) compiles like the plain `v + err * k`: uopt deletes the overwritten store (Q0073) and forwards the value, removing a reload the target performs (bonusSearchlightSeekGameUpdate 0x5e78: 88 lines), so a direct field write cannot stand in for a local whose reload the target shows.
