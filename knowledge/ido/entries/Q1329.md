This is the sibling idiom of controllerAnimSetStateRemap/RemapDirect (17B90.c:425/441, untagged). The redundant u16 x copy and cast are gone. FAKE 2 -> 1 in the file. DIRECTOR RULING (turn 90): ordinary C (one value refined in place with a real, used store; sibling precedent). 1. (uopt; related Q0535, Q0508, Q0451, Q0199) A parameter reassigned with the value it then passes avoids the argument-register conflict. A u16 parameter whose only use is in the same block as a call cannot take a1: it shows forbidden [1 3 4 5 6] and is reloaded from its home with lhu. Reassigning the parameter with the looked-up value and passing the parameter itself, unconverted, as the a1 argument keeps it coloured a1 in one block, with no dead test (0x1134, 0x1144-0x1154, 0x1170). A separate index local is still needed so the sum gets v0. 2. (cfe; related Q0311, Q0411, Q0424, Q0826) A K&R definition cannot have an f32 parameter. Under any prototype, a K&R definition with an f32 parameter is a cfe Error ("not compatible with the type after applying default argument promotion"); a narrow integer parameter there is only Warning 642. With no prototype, the f32 arrives as a double in a2:a3 (`mtc1 a3,f12; mtc1 a2,f13; cvt.s.d`). So a function that receives a single-precision float in a2 or f14 has an ANSI definition.
