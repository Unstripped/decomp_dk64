A local assigned a constant and used only where uopt propagates the constant still contributes its assignment and every use to its own adjsave, although the code is identical to the literal. A uniform "size local per chunk" idiom is therefore a natural priority lever that can replace reused-temp hacks.

Evidence: recordInitPositionBuffers (global/10130.c, FAKE 1 -> 0): `byteCount = sizeof(D_807463B0); memcpy(..., byteCount); src += byteCount;` (code identical to `memcpy(..., 2); src += 2;`) raises byteCount 3.0 -> 4.0, above src's 3.25, and swaps their $s0/$s1 colouring, replacing the hack `byteCount = src + byteCount`.
