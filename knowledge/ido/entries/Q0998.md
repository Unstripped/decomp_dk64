Measured refinement of guide ido-uopt-statics-and-live-ranges#7: for a u8 conversion (ucvt) piece, adjsave = (uses - reload blocks) / blocks, and each empty label block whose predecessor lies outside the piece (for example a call-path block) counts as one reload. Labels can therefore push a candidate to zero savings and leave it uncoloured. Check a candidate's count with `uopt_trace -l 5` "live bb" flags (needreglod) and the pre/suc CFG listing before diffing.

Evidence: camComputeEyeFocus (global/201B0.c): the two after-switch labels (look_set/look_done) raise reloads from 3 to 5 against 5 uses, adjsave 2/7 -> 0, so `type` stays uncoloured; this is why the gotos match.

**2026-11-17 correction (HackcamComputeEyeFocus6, merge 753a2f0e):** not consecutive after-switch labels specifically: any empty goto/label block entered from outside the piece counts as a reload block (camComputeEyeFocus piece 1029: 5 reload blocks bb127/146/175/176/185 vs 5 uses, adjsave 0).
