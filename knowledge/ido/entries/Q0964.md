In `HackenemyAggroStateUpdate2` (cleanup unit 2026-11-15, commit 97a9f3) the kept spelling is `(ret ^ 0) == unk36`, the Q0488 lever. Declaring `ret` as a `u8` local to hold the `u8` call result does give the field-first `beq t5,a0` the target wants. But uopt then re-masks the result (`andi a0,v0,0xff`), and the me/near stack slots move by 4, so the best score was 22. With `ret` declared `int` the score is 36, and with `unsigned int` it is 1. Retyping the callee `behaviourCheckTargetCollisionMode` to return `u32` still matches the callee, but the caller's plain compare stays at 1. Unlike Q0128, a narrower or `int` local type does not fix operand order on its own here. The `u8` local fixes the `beq` order but costs an extra mask and changes the frame layout, so `^ 0` is still the lever to use.
