Unlike an empty `if (global) {}`, which emits nothing, an empty `if (call() < x) {}` keeps the call, the compare and a two-way branch to the same merge at -O2. So an empty test on a call result in a matched function is usually original code (`// ORIG:`), not a steer.

Evidence: critterBananaFairyUpdate (critter/3340.c): site 29956a is ORIG at 0x5ec-0x604 (lead-verified).
