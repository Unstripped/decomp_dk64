When a parameter used both as a pointer and as an integer (id, cursor) is retyped to its pointer type, the integer roles need a new local. An existing unexplained `s32 pad` can be exactly that local's slot: declaring the new local in the pad's position reproduces the frame, any other position shifts the save slots, and keeping the pad as well grows the frame. This retires the parameter-reuse steer and its cfe warning.

Evidence: actorMapModelsSetup (global/8D3E0.c, now `(u8 *, u8, u8)`, merge ca506697): other positions first differ at 0x74 / 0x44; keeping the pad grows the frame 0x60 -> 0x68.
