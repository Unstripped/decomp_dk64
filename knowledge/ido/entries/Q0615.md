In `animIsPlaying` (8CA50), `return (node->unk22 == 0) ? 1 : 0;` matches; `return !node->unk22;` compiles 16 bytes shorter (the branchy ternary arms become a straight `sltiu`). When the target returns a boolean through a branch with two `li` arms, write the explicit ternary, not `!x`.
