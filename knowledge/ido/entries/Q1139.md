HackbonusTargetGameUpdate (unit "2026-11-16c: cleanup HackbonusTargetGameUpdate", merge 0a7cfd1f), src/bonus/2690.c (cfe/uopt): in `s->u8f = f(); g(s->u8f);` with `g` taking s16 and `f` returning s16, the stored value is carried into the field read keeping only the u8 mask (`andi aN,v0,0xff`, `sb v0` stores the unmasked v0) with no `sll/sra 0x10`, because a u8 field read into an s16 parameter needs no sign extension; a u8 local passed the same way gets sll/sra. So a u8-local callee prototype steer (local `void g(u8, f32)` + PROTO_SKIP) can be removed by dropping the local and passing the just-stored field. Evidence: bonusTargetGameUpdate 0x11c0-0x11dc, same in bonusLightFlashGameUpdate and bonusBigBugBashGameUpdate (func_806FDAB8 with the shared 1025E0.h s16 prototype). See also Q0666, Q0188, Q0750, Q1012.
