A compare chain on an element that was just stored (`a[i][k]--; if (a[i][k] <= 0) ... else if (a[i][k] == 11)`) re-reads the element after the store and hoists the literal, giving a constant-first compare (`bnel tK,aN`) like a `11U` literal compared with a loaded local. Write the natural re-read instead of the unsigned-literal hack.

Evidence: controllerUpdate (global/F600.c): `D_807ECD68[padIdx][k]--; if (D_807ECD68[padIdx][k] <= 0) ... else if (... == 11)` emits `bnel t4,a1` (lh a1,0(a0) re-read after the store, li t4,11 hoisted).
