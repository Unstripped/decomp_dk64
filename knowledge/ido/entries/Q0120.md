IDO references `.rodata+off` or `D_807F72B8+0xA0` where the expected asm names a label (`D_8075A220`, `D_807F7358`); `objdiff.sh` reports `Relocations mismatch` and the ROM hash decides (`projectileActorUpdate`, `mapSearchTableReset` matched that way). The same message also hid a real one-instruction scheduling difference in an earlier `mapSearchTableReset` draft, so only identical objdump instruction streams count as reloc-only.
