In `projectileSteerTowardTarget` (src/global/936B0.c, ledger-only Hack projectileSteerTowardTarget2, base a04efaed, kept 8a4e49), a K&R unsigned narrow formal (`u8`) gets its own widening candidate (ucvt cand 39), and uopt PREs it across a call. It is loaded into v0 at 0x2358, stored with `sw v0,0x38(sp)` in the jal delay slot, then reloaded with `lw t7,0x38(sp)` at 0x2434. The target has `lbu t8,0x8f(sp)`, which reloads the formal's home instead. A signed narrow formal (`s8`/`s16`) gets no such candidate because the sign extension folds into `lb`/`lh`. So `s8` matches except for the load opcode (full=4), while `u8` scores 55. The lever is to take `&straight`, the formal's address. That makes the formal non-vreg, so the call kills it and each use reloads the home slot, as the target does. Unit "2026-11-15: cleanup HackprojectileSteerTowardTarget2".
