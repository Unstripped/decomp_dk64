In `textLayoutAppendCommandList` (112080) `u8 *text = span->offset + parsed->payload;` replaces the `res = parsed` copy steer (713f05). The commuted `parsed->payload + span->offset` does not match: the addition's operand order decides which value stays in the register the copy used to pin.
