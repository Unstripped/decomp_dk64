`if (s != 0x34 && s != 0x36) { x &= 1; } else { x = 0; }` needed a dead `if (sub) {}` and `pred |= 0`; `switch (actor->state) { case 0x34: case 0x36: x = 0; break; default: x &= 1; break; }` matches with neither: the switch fixes the register of the state byte and stops copy propagation of the earlier `||` result. Evidence: `playerCanTakeHit` (EFDC0).
