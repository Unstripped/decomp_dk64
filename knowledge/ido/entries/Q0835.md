Corrected 2026-11-15 (HackgfxBuildScrollingBackground2, merge c3677d79, ledger f14d4750): the earlier claim that a static stores an s16 without narrowing is wrong. `sBgScrollX += 4` on a function-local `static s16` narrows with `sll/sra`, stores the narrowed value and compares it, matching the target at 0x2cf4-0x2d04; only `t = s + 4; s = t;` stores the un-narrowed `v0`. A missing sll/sra pair is therefore not a reliable sign of a function-local static. gBgScrollX/Y (the TU's last file-scope .data, used only here) became function-local `static s16 sBgScrollX/sBgScrollY`; for where IDO places such statics in .data see Q0761.

Evidence: gfxBuildScrollingBackground (global/109660.c, 0x2cfc/0x2d04).
