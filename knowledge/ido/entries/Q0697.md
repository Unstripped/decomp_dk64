A narrow callee parameter fed by a constant ternary can change register allocation far from the call. In boss/0 `bossArmydilloStep`, declaring a callee's parameter `u16` and passing `c ? 0x210 : 0x212` adds a uopt live range for the selected constant, and that forces a stack spill of an unrelated index ternary about 330 lines earlier in the same function. Narrowing only the u8 first parameter or the return type of the same callee is codegen-neutral. When a prototype change moves a spill in a distant part of a large function, check the constant-ternary arguments of that call first.
