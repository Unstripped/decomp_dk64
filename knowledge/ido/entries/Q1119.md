Same unit/function (extends Q0025, Q0826): a K&R definition is proven by one same-file call site AFTER the definition: if the callee body needs the narrow parameter type T (u16 here, keeping the hoisted spill) but the caller passes a value a T prototype would convert (sll/sra with no andi 0xffff, camPathCommandDispatch 0x3e0-0x3ec), no prototype was in scope and the definition was old-style. This is the call-site evidence Q0826 asks for ((u8,u16,u8) matches only the callee, (u8,s16,u8) only the caller).
