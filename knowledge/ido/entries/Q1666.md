Director ruling R-oildrum (2026-11-25c; short form in .omp/skills/cleanup-unit/rulings.md, ORIG section). A local reused for an unrelated second role whose value never reaches the local's home (R5) is ordinary C, untagged, only when all three parts hold and the function's dossier records the census (positions tried with score and what moved, no-local spellings with scores, role ranges); otherwise it stays `// FAKE`.

1. Frame proof: splitting the second role into its own local changes the frame size or moves a home or a spill at EVERY declaration position: function scope before and after each existing declaration, block scope in the arms where the role lives, `register`, and real-type narrow widths in alignment holes. Register-allocation-only evidence does not qualify: adjsave, $f0 vs $f2, or a split that keeps the frame and every named home, including a narrow role in a hole whose only effect is spill traffic of the register assignment (12E800 enemyAggroStateUpdate `near`: u8 split in the byte hole keeps frame 0x58, only near's `sw t4,64(sp)` spills vanish: FAKE stays). The stack change must come from the new local's own slot (uopt spill temps displaced by it count: ACDC0 hudPauseMenuIconUpdate, 3E10 menuUpdateElementTargetAndColor `t`), not from a register reassignment; a register change on top of such stack evidence does not disqualify (ACDC0 3490af/dddb5b). A placement whose width changes the value is not a legitimate position (55B20 mapNodeTriangleContainsPoint: an f32 split keeps the frame but rounds the f64 product, 22 cvt lines; the f64 split grows the frame everywhere: passes).
2. No-local proof: every ordinary-C spelling without a local for the second role fails (a matching spelling that is itself a steer, such as a re-read the target does not do or a value-changing width, does not count: 3E10 `t` reads stick_x once, `lb` 0x9114, so the inline re-read form is excluded): the expression inline at each use, the field read repeated at each use, a direct field/array write, a pointer local, a function-local static. Two sites fell here instead: 3E10 menuHandleControllerSlotInput `mask |= 1 << j` and D5E10 playerStateLandRecover's frame read at each compare both match, so the reuse was a hidden steer and the no-local form replaced it.
3. The two roles share the local's type and live in disjoint regions (cite lines and asm ranges), with a real plausibility argument; when the local's name names only one role, rename it to a role-neutral name with a declaration comment listing its roles (ACDC0 `radius` -> `tmp`, BA790 `x` -> `tmp`).

Applied this unit: arcade/0 arcadeUpdateOilDrumEntity `n` (18 positions move the cfe temp -8 -> -12 and the a1 spill 0x1c -> 0x18), ACDC0 hudPauseMenuIconUpdate (6 sites), BA790 chaserEnemyStep (a split removes the home stores at 64(sp) 0x494-0x4b8 / 0x618-0x620 and shrinks the frame 0x50 -> 0x48), 6AD90 collisionCheck(Box)TriangleContainsPointXZ (M21's frame fact, Q1545, is part 1), 55B20 map(Node)TriangleContainsPoint. Failed: 12E800 near, D5E10 playerStateSurfaceTreadWater, arcade/0 arcadeSpawnStage4Enemies / arcadeDrawHud, ACDC0 hudPauseMenuRender (6) / hudPauseMenuUpdate (2) (each: a frame-keeping split exists).
