Supersedes Q0110 for this shape: a search loop that needed a trailing `continue;` steer matches written as `if (match) return 1; else i++;` (the increment only on the miss arm), which gives uopt the same block shape. It matched twice in 55B20: `mapPointIsInRenderedChunk` and `mapNodeIdListContains` (the Q0110 function).
