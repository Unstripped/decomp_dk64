In IDO 5.3, copying parameters to synthetic function locals ('aN = argN;') can create artificial register webs that require dead-read FAKEs ('if (aN && aN) {}') to steer register priority. Forwarding the function parameters directly removes the unnecessary local copies and the accompanying dead-read FAKEs.
