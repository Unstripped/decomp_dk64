Same unit/function (uopt copy propagation / PRE): a u16 index whose defining expression reloads a global is not copy-propagated across a call (has_ilod), but when the same value was computed in the arms of a preceding if/else, uopt's redundancy elimination reuses it only from an arm with the identical expression tree; an arm computing it in step form (x = ...; x += ...; x &= ...) gets an inserted recomputation. Evidence: `b = ((REC / 8 + 0x40) / 4) - 1` after the arms 107: b stays s2 before the call, arm 0 gains a duplicated `li at` chain into a2, arm 1's single expression is reused. See also Q1008, Q0546.
