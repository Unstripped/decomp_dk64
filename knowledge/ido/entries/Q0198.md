uopt hard-forbids `$v0` for any candidate whose live range contains an `s32` callee call whose result is ignored; a `void` callee never forbids it, and changing one callee's return type recolours globally. When one file needs `s32` (a caller uses the result) and another function needs `void`, a dead `if (callee(...)) {}` around the ignored call gives the `void` colouring (`func_806D4758`, `func_806D4A70`).
