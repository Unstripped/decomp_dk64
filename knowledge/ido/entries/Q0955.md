In `hudPauseMenuRefreshTotals` (global/ACDC0.c), IDO's strength-reduced loop puts the array base plus the starting induction value in the base register and keeps the constant index term in the load/store offset. The target uses the interior splat labels `D_80750531` / `D_807505B2` as bases, read as `label[i - 1]` with -1/-2 offsets. Rewriting them through the parent symbols as `D_80750530[i + 1] = flagGet(D_807505A4[i + 6])` gives fdiff 1, and so does a 1-based loop version. The folded offset is tied to the symbol the code names, so the interior labels have to stay. A related case in C1E70: changing `sRingExits` from flat s16 pair indexing to a `{ map, exit }` struct array shifts the ugen temps, as Q0167 describes, so it stays flat.
