Extends Q0905/Q0802. Once a TU's .data is defined in C, a function-only template global copied into a local can be written as the local's own aggregate initialiser: IDO emits the template at the same .data offset and reaches it through the .data section symbol plus an addend instead of the carved `D_` name, so the object is RELOC-EQUIV (raw words equal except the HI16/LO16 symbol+addend). arcade/0: arcadeInsertHighScore 0xa54 (.data+4, `u8 blank[1] = { ' ' }`), arcadeDrawTitleText 0x2698 (.data+8, `s32 titleBitmap[12]`), arcadeSpawnStage2Entities 0x445c (.data+0x8c, `u8 pos[8][2]`); .data bytes identical, the three globals and their wrapper typedefs removed.
