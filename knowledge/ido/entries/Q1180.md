A signed constant used once before a switch (in a store or a compare) carries its web across the jump table, so the signed uses in the cases share one register. Making either end unsigned (the store, or `u8 != 1U`) splits the web. In 80150 transformBarrelUpdate 0f5fc9 the bridge is case 4's `unk2C0 != 1`, not the hide stores. `!= 1U` gives 0, but it would swap one steer for another, so it was not adopted.
