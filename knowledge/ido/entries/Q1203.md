Extends Q1156 to switches. In boss/3840 bossScriptStep, `for (;;) { switch (op) { ... } break; }` with an arm ending `op = 0x42; continue;` still branches back to the range check and jump table (`b 0x3c8`, slti/jr dispatch, at 0x904/0x938/0x9a0/0x9dc with s0 = 66); uopt never jumps straight to the known case. The loop also promotes locals to s0-s4 (frame 56 -> 72), full=577. So a cross-case goto into a shared tail cannot be rewritten as a re-dispatch loop.
