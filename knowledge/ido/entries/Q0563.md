(1) `cupcosts` (uopt): a variable with two separate webs in blocks X -> Y, where X ends in a call, is costed as if it crossed the call and gets a callee-saved register; to get a caller-saved one, put a block boundary so the first web's block has no call (`mapChunksInitFromMapData`, leftovers revisit 13: an `if (arg0) {}` boundary gave the boxes holder a0). The same pass found the priority divisor quantisation of Q0523 deciding arg0 (savings 76) vs the -1 constant (69) until one arg0 use at loop weight was added, and moved the park 213 -> 49 by deleting old guards that blocked PRE re-insertion of `&gMapChunks[n]` after a call. (2) Frame parity (`camPathCommandDispatch`, park 172 -> 57 with frame and items exact): spilltemps items start right at the Mmt bottom only when no align8 hole is needed; with Mmt length 92 (4 mod 8) the lowest Mmt object had to be a 4-byte hidden cfe temp allocated after the two f64 temps, otherwise a hole appears and the items shift by 4. Two simultaneously live 4-byte ternary temps (`ABS(a) <= 0 ? 0 : ABS(a) - 1`) supplied it. Item bits follow creation order in the post-local-opt stream: a never-overwritten variable's dead store keeps `ushr(arg1,16)` alive early, while `a = shr; ...; a = (s16)a` loses it (the first store is locally dead); inline `(s16)((u32)x >> 16)` at byte-store sites folds the cvtl and leaves a standalone `ucvt` item (one slot too many), named copy-propagated variables keep the chain.
