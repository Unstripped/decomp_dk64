A stride-pointer clear over a constant array, written `e = base; for (;;) { e->type = 0; e++; if (e >= end) break; }`, and the plain `for (e = base; e < &base[N]; e++) e->type = 0;` produce identical code: with both bounds constant IDO knows the loop runs at least once and rotates the plain `for` into the same bottom-tested loop (no unroll for a struct-stride body). Rewrite such m2c break loops as a plain `for` (arcadeInitTitleScreen, cleanup round 9).
