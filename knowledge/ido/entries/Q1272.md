File src/global/67890.c, actorTargetTableLoad 87ac3c (fixed). Extends Q1140 (see Q0408, Q0372, Q1179): a `sw zero,X(sp)` at entry plus one reload before a loop shifted by log2(element size) is a strength-reduced array index `buf[n]` / `n++`. The zero store survives only if the original `n = 0` comes before calls: its live range then has negative savings ("not colored (-ve save)") and stays in memory; placed after the calls the 0 folds and the range disappears (206). Its stack offset follows declaration order counting the register-only locals declared before it (Q0408), so no stack array or volatile is needed. Evidence: 0x8, jal 0x44/0x68, 0x98, 0xac. Pattern to look for elsewhere: any `start[0] = 0` / volatile-zero seed of a vertex or buffer walk.
