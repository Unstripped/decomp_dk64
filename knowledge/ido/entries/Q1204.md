cfe uses ONE temp for every `x-- > 0` / `elen < width--` loop test and for the `(prec > 0 || alt)` value; uopt allocates it as one function-wide range whose register is the first one not taken by a higher-priority range sharing any block with it. A high-priority counter reused in another arm therefore supplies that block with no code. Evidence (boot/3D20 vsprintf): the -324vreg temp (priority 285) gets v1 only while d (-40vreg, 636.9) is live in f-arm block 308; with a separate i2 as the f-arm counter it gets v0 (154 lines). This replaced the dead `d = width ... if (d) {}` pair.
