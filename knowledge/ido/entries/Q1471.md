2026-11-18 static-data unit (menu, global 0x1492E0-0x14C9E0 carves): splat labels at a field offset (D_80744834 = D_8074482C[].overlayBufferSize, D_80746344, D_80747D84, D_80747E10), at a loop-end address (D_80744746, D_80747E64), below an array from a constant index offset (menu D_80032F48 = D_80032F54[h][step - 3] base, D_800330C0 = D_800330C4[step - 4]) or at the low half of an s32 element passed to an s16 parameter (D_800330A2 = D_800330A4 - 4 + 2, lh +2; cf. Q0594) come from the compiler folding constants into %hi/%lo. Defining the parent object in C makes them disappear from the relocations (splat only keeps them in its generated undefined_syms_auto file): no rename.py fold is needed. Only a label the C source names directly (D_80744736 = &D_80744734[1]) needs an absolute undefined_syms.us.txt line. data_owners.py shows such labels as objects without owners; check `grep -rn <label> src include` before folding.
