`sizeof(t) / sizeof(t[0])` written inline in a loop test is a size_t constant, so the compare is unsigned: it keeps the `sltiu` test and blocks uopt's end-pointer rewrite (LFTR) exactly like a `U` literal. It is the natural form for a target with an unsigned count test over a data-sized table; contrast the signed bound local of Q0780 (68960/F93B0).
