In a loop, `slots[index + i]` strength-reduces to `addu s0,a2,t6` (base register first), while hoisting `slots + index` or `&slots[index]` emits `addu t6,a2`. When the target puts the base first, index the array inside the loop rather than hoisting `base + index`.
