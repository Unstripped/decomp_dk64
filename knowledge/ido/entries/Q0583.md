Q0554's FIFO scratch ring is wider than `$t6..$t9`: ugen's queue is **every scratch register uopt did not colour anywhere in the function**, initial order `$t6 $t7 $t8 $t9 $t3 $t4 $t5` (`14 15 24 25 11 12 13`). In hudPauseMenuRender (uopt uses `$t0..$t2` for case-2 temps) all seven cycle; removing a dead deadsweep test at the function end freed `$t2` from uopt and it joined the ring (`sll t2,t9,2` for the loop-1 index), so a FAKE far away can change ring names everywhere. Exclusion is whole-function in every matched example (a `$t3` web in `playerViewGfxSetup`/`func_80709890` never reappears as a ring name), and a coloured register that dies rejoins the queue at its last use (planePolyCalcEquation, `$t3` web 36–55).

Rules confirmed on the matched corpus (`tools/ringfifo.py corpus`: 4391 functions, the rest explained by the gaps below): front allocation; a register is appended when its value dies — operands in textual order, a dead definition immediately, the third (scratch) operand of `trunc.w.*` immediately (1628/1628 truncs carry a scratch and the `mfc1` always follows directly); the index register of a symbol-indexed load into an `$s` register (`lw $18, SYM($11)`) is freed at that load (73 later re-allocations confirm it). Gaps: 64-bit values and struct-copy idioms allocate an **aligned even/odd pair**, skipping an odd front (`lw $12,16($10); lw $13,20($10)` with `$11` at the front), and free it as a unit even-first (camCueTimerTick `$t6/$t7`, tagBarrelUpdateSelectedKong `$t8/$t9` src/dst); struct copies may leak a register for the rest of the function (volumeTriggerTableLoad `$t3`); `jal $25` reserves `$t9`; the `cfc1/ctc1` idiom picks its own registers. The model also mis-parses `$$N` string labels as registers: strip them.

Use: `tools/as1probe.py keep` the candidate, `tools/ringfifo.py sim DIR FUNC` and read the queue at the first label whose body names differ from the target; the target's names fix the queue order there (its first allocations are the queue front), so the mismatch pins the block where one free or allocation happened in a different order.
