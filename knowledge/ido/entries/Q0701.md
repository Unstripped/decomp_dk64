In func_80610268 (14CF0) the received message lives in a variable whose address is passed to osRecvMesg. Comparing that variable directly against a parameter emits bne param,var (bne t8,s1 at 0x2e8); the target has bne s1,t8. Copying the value into a plain local first (single mask, store into receivedMsg, then copy to receivedTaskId) restores bne local,param order with fdiff 0: the address-taken variable is ordered as a load. The target also really stores the masked id back to sp+0x34 (behaviour, not a steer).
