`n = 0; while (a[n++] != S) {}` produces the same rotated loop as a pointer walker (`n = 1; while (*p++ != S) n++;`), but uopt strength-reduces the index into a `uixa` cursor that starts in the loop preheader, so it can take $v0 with no restriction from a call earlier in the block, and the base pointer keeps only its store use. The walker's first-test and +4 uses raise the base pointer's adjsave and break ties with neighbouring address candidates. Where a walker loop needs dead-if block splits or `+ ((s32)x * 0)` reference steers, try the index form first.

Evidence: meshBlobParse (global/10E1D0.c, FAKE 5 -> 0): cursors (bits 39/71/89, adjsave 15.5) in $v0 at 0x474, 0x4dc, 0x528 with no dead-if split after the heapAlloc call; walker uses raised the base pointer 3.0 -> 4.0, while in the index form blob+0x2C/cells/columnCounts tie at 3.0 and take a0/a1/a3.
