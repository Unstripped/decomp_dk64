In `critterShowText` (critter/4840), replacing the local s32 `textGetStringWidth` steer with the owner's real `(s16, u8 *)` prototype swaps the address `addu` operand order (a1,t8,v0 vs a1,v0,t8). Five argument spellings were tried and none restores it, so that file keeps its steer pair.
