A reused local is ONE candidate. Splitting it into two role locals adds a neighbour in the interference graph, which can push another web to the constrained threshold (degree >= 22) and change colouring; the split can then replace a dead test that was providing that neighbour.

Evidence: pathPlaybackAdvance (global/127B00.c): the `overshoot` split replaced a folded dead `path == 0` test (its constant -4 web 203) as the 22nd neighbour of pb and the -1 constant (removal 299 -> 9 -> 0 with the pb-in-test head).
