a callee returning `s32` passed directly as an outgoing stack argument gets a 4-byte temp home (+8 frame; a `u16` return avoids it); scalar pads optimised away still leave an aggregate `u32 pad[N]` slot; scalars declared before an array sit above it, after it below; a value assigned on only one path of an if/else is spilled (assign it before the branch); a shared temp (abs value, call result) reused across several blocks gets a saved register or spill - inline it or block-scope it per use; `u8 failed; failed |= 1;` lives in `$fp` where `s32` spills.
