For an `s16` argument written as `param2 + T[param1]` with `T` a `u16` table (C4620), IDO 5.3 loads the table element (the index operand) first whichever order the source uses: `param2 + T[i]` and `T[i] + param2` give the same load order. Only the subtract-of-negation spelling `param2 - (0 - T[i])` loads `param2` first and matches the target. This is another operand-order lever to add to those in Q0363; check the asm before calling such a spelling a hidden steer.
