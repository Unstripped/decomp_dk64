A chained assignment through a struct field stores and then reloads the field, the same code as the two statements `s->f = K; a = s->f;` (with an s16 field: `sh` then `lh`). A target store-then-reload pair can therefore be written as one chained assignment. Contrast Q0107: a chained store to a global changes the schedule.

Evidence: spawnNodeListInitFromMap (global/1295B0.c), five sites, fdiff OK (merge d0b94062); 13A7A0's `state->next = state->prev = NULL` matched the same way.
