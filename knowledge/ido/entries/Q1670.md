`i = 0; if (n > 0) { do { ... } while (i < n); i = 0; }` followed by a second guarded do-while compiles to the same object as `for (i = 0; i < n; ...) { ... }` twice with the shared counter (renderBannerText: full=0, merged 8a4c94b9). Prefer the `for` spelling; Q1616 covers the single-loop case.
