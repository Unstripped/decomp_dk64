Extends Q0410 (constant-trip loops peel iteration 0) to an early-return search loop, and Q0741/Q0679 (m2c split-label loops are plain array loops). `for (i = 0; i < 9; i++) if (map == t[i]) return 1;` over a u16 table is compiled with iteration 0 peeled: a `t[0]` compare before the loop, then a loop based at `&t[1]` with the end pointer `t + 0x12`. m2c shows it as a separate `[0]` test plus a loop over a split label.

- The plain loop over the parent array: RELOC-EQUIV OK.
- `for (i = 1; i < 9; i++)` after an explicit `[0]` test: also passes.
- Re-based loops from 0, `t[i + 1]`, `(&t[1])[i]` and `*(t + 1 + i)`: fail (the base pointer and load offsets change).
