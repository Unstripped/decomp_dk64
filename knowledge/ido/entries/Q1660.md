In transformBarrelUpdate (site 0f5fc9), a block-scoped `Actor *actor = gCurrentActor; actor->flags |= 0x8000;` in the allowed arm gives the same code as the `*(u16 *)&gCurrentActor->interactionType = 1` pun on the plain s16 store (the target reloads gCurrentActor on the next line, `lw t6,0(t1)` at 0x3920). The local's frame word is absorbed by `u8 itemCount` (`lbu a0` at 0x3800) and `u8 allowed`; with the alias alone, only the case-3 sound home moves (sp+98 -> sp+94).

A pointer local used once while the next line keeps the global is a redundant alias (rulings.md), so swapping the pun for it trades one hack for another. The pun stays FAKE (lead ruling, 2026-11-25).
