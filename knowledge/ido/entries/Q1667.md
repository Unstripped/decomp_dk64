Q1643's lever (one cfe temp carrying a switch selector and a later `?:` value, no user local) needs that value to be used as a value: a call argument or a second switch. Two cases where the precondition fails:

- `lhs = c ? a : b;` as a plain assignment: cfe lowers it to a conditional store in each arm (`fjp` lab 12/14, `istr` per arm) and defines no temp. playerWeaponCalculateTrajectory7: target 0xe14 `beqzl t4`, then `sh v0,4(t8)` 0xe2c in one arm and `negu t9,v0` 0xe34 / `sh t9,4(t3)` 0xe40 in the other; the bound is the immediate `sltiu at,v1,7` at 0xd94, so the `angle = 7U` reuse (Q0214) has no cfe temp behind it.
- A single `switch` on a plain local with no second role: the switch temp is copy-propagated and never becomes a live range (renderBannerText, CBEA0: `-212vreg`, candidate bit 114; the case compares read the side variable directly, bits 224-227), so it cannot carry the later line counter.

Check the cfe ucode (`as1probe.py keep`, `ucode --cfe`) for the temp before transferring Q1643.
