A loop bound held in a local assigned `sizeof(table) / sizeof(table[0])` (the ARRAY_COUNT idiom, with the extern array sized from its data) keeps `slt` with the bound in a register and blocks peeling/unrolling and the end-pointer (LFTR) rewrite, exactly like a value-named `limit = 13` local (Q0263, Q0765). Written inline in the test it folds to a literal (`slti`, unroll or LFTR). Use it only when the data proves the table length (the next data label gives exactly the bound).

Evidence: mapUpdateFogDistance (bd41252b), mapGetVoidHeightForCharacter (88a3e47a), particleFindPathIndices (global/699B0.c) and six global/135D30.c functions (9956756b); director-accepted as natural.
