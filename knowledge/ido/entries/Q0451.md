uopt interference is per basic block. Reordering statements inside one block does nothing; moving a variable's first definition into another block (inside an `if`), or nesting code one level deeper (`if (!(c)) { rest }` instead of an early `return`, which cut a narrow parameter's priority 0.5 -> 0.333), changes which candidates share a register. A move-one-statement sweep found which block held a parameter's last use.
