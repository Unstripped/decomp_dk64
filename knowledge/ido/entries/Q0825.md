uopt does not coalesce a local copied out and back around a clamp (`newState = state; ... state = newState;`): the pair survives as a real `move` plus a stack spill of the copy. Such a pair in m2c output reproduces a target `move` and spill word that no single variable explains, but it is a steer (tag it FAKE), not a natural spelling.

Evidence: effectDecelerateDriftUpdate (global/11BC10.c): `move v0,v1` at 0x2bb8 and the copy's spill at 0x1c(sp); removing both lines gives full=9; tagged FAKE 3658da/5c1124.

**2026-11-15c correction:** the copy round trip is NOT original. The target's `move` + spill in this alloc-if-NULL effect callback comes from the Q0375 head with one local: `if (p->f == NULL) { s = alloc(); p->f = s; ... } s = p->f;`. PRE reloads p->f only on the init path, so the field-load temp and s stay separate webs joined by `move v0,v1`: early uses go through the temp (v1), later uses through s (v0, spilled to its home). `s = p->f; if (s == NULL)` instead makes one web (full=9). Evidence 0x2bb8/0x2db4, fdiff 0 (effectDecelerateDriftUpdate/effectSpiralRiseUpdate, unit "2026-11-15: cleanup HackeffectDecelerateDriftUpdate", 15c0e8e8).
