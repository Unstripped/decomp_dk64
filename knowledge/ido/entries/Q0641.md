In `func_806B1F50` (B6C50), a `break` inside an `if` in the switch's last case is redundant C (the original may or may not have had it). The rewrite that contained it matched and replaced tagged site 4bf73e; it is ordinary C, not a hack.

Corrected 2026-11-14 (RereviewW2Global, merge c848fa0e): deleting that `break` entirely leaves the code unchanged (fdiff 0, ROM gate OK), so it does not shape the exit branch. What matters is its position: moving it outside the `if` adds a branch to the switch exit (+32 bytes). The match that retired 4bf73e came from the rest of that rewrite, not from the `break`.
