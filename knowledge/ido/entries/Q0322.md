one access to an extern global in a block gives `lui; lw %lo`; a second (a store, a read through the stored pointer) hoists `lui/addiu` and uses `0(vN)`. Reading the same global through an alias symbol (`*(u16 *)&D_807FCC40[4]` for `D_807FCC44`) un-shares it; `*(s32 *)&D_x[4]` as a second read defeats load CSE. `f32 *p = &D_x;` read as `*p` in a call's arguments schedules the FP load after the integer args.
