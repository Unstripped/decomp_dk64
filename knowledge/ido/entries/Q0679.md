In boot/1CC0 `inflate_dynamic`, the original's `&border[j] < &D_8000EDF3` loop end (a splat label 19 bytes into `border`, Q0489's LFTR shape) can be written as the plain `for (; j < 19; j++) ll[border[j]] = 0;`: `fdiff --reloc-ok` reports RELOC-EQUIV OK and the ROM gate matches, so the split label is retired. Compare against the next splat label only when relocations must match exactly.
