IDO drops the loop counter (LFTR) with a reloaded bound only when the body is a `switch` with a `default:` (an `if` or one-case switch keeps the counter). A rotated `while (!done)` gives post-loop code its own `lui/addiu` base; `do {} while (!done)` keeps one hoisted base. A long empty case list blocks hoisting `&global` into a saved register; a single `case 0: break;` keeps the same jump table. `if (a[i++] == K)` makes a value-form cfe temp (forbidden `v0`); `for (...; i++) if (a[i] == K)` does not.
