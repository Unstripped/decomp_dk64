`v = p->f; v = e - v;` counts 2 defs + 2 uses in adjsave though the asm never holds the load in v, whereas copy-propagated arithmetic first defs, dead pre-reads and constant first defs are dropped before counting. Corollary: if A must outrank CSE load L but A is computed from a value numbered after L, only adjsave can win; declaration or statement order cannot.
