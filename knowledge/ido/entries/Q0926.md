This extends Q0601 with a boundary condition. In `slotQueueGetValue` (4ccde5, unit "2026-11-15: cleanup HackslotQueueGetValue"), a dead-read hack could be replaced by a named pointer local, but only in one shape. The test had to stay on the field, `if (p->f != NULL)`, with the named pointer used only for the dereference inside the branch. A pointer local that also carries the NULL test (testing the local instead of `p->f`) does not replace the dead read, and the hack is still needed. So when you try Q0601's named-pointer lever to remove dead-code steers, keep the original field expression in the condition and bind the local only for the body's use. Moving the test onto the local changes how uopt treats the load and loses the match. The queue line gives no separate merge commit or evidence path beyond "same merge" as the Q0601 follow-up.
