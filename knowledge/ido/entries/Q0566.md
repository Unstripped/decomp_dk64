mapChunksInitFromMapData initially had identical instruction text but one wrong branch displacement: the -1 sentinel branch entered the `lw pointer; addu entry` reload instead of skipping both. That reload belongs only to the preceding store arm; the bypass already has the correct entry pointer. Normalized deadsweep text/shape scoring erased the branch targets, so the full ROM comparison was decisive.

After updating entry.unk8, the existing dead `if (arg0) {}` became `if ((u32)arg0 == (u32)((MapRelocEntry *)D_807F6C0C)[i].unkC) {}`. The field read keeps the pointer reload in the arm, while arg0 retains its loop-weighted priority above the -1 constant. A separate dead field guard also fixed the target but changed block weights and register allocation; combining both operands in one guard preserved both. All evaluated data is initialized and the same field is read immediately afterwards. The construct is FAKE-tagged. Explicit local-entry rewrites reproduced the control flow but changed induction-variable selection or globally coalesced pointer registers; a single-edit as1 scan found no improving record change. Full ROM hash and isolated linked-MIPS sentinel cases passed.
