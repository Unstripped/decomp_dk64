Extends Q0759 (a pointer local copied from a field adds a spill; reading the field matches): an `Actor *actor` local that is re-assigned from `node->actor` after each call compiles the same as writing `node->actor` at every use, so it can go. Its declaration must go too: left declared but unused, it still takes a stack slot (frame 0x80 -> 0x88, Q0027).
