Before trying pad locals for a frame difference, check whether the difference is the callee-saved register count. A variable kept in a register for a whole loop raises pressure and pushes hoisted loop constants into s registers; removing it saves fewer s registers and shrinks the frame, and no pad word can stand in for it.

Evidence: gfxSwapGeometryModeCullBits (global/17B90.c): removing the dead `command` test (command in $a2 for the loop) drops the frame 0x18 -> 0x10 because s0-s3 saved at 8-0x14 become s0-s1; a `pad` instead scores 52, the same as removal.
