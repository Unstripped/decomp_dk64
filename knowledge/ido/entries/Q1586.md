In sfxUpdateLevelAmbient (global/7130.c) `if (gAmbientIndoorReverb) {}` kept &gAmbientIndoorReverb out of $s4. Written as `emitters[nearest].f`, the element address is recomputed per block as separate candidates, which leaves room for the address web of the global to be coloured. One AmbientEmitter *entry reassigned at the start of each of the four blocks (`entry = emitters; entry += nearest;`) is one variable in $s0 across blocks (0x14a4/0x1668/0x23f0) and the global's address stays uncoloured with no dead read. Every block needs the base-first spelling (`&emitters[nearest]` is offset-first, text 50; mixed 30-88, Q0813). The 4-byte pointer fills the never-accessed word sp+0xe0, which is why the function needed `s8 pad` (removed; u8 emitterCount moved to its byte slot 0xe6). With the pointer, `D_80770DD8[1] = entry->sfxId` also retired the D_80770DD9 linker alias (reloc-equivalent).
