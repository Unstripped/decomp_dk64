Relates to Q0813 (typed `&p[i]` spellings give an offset-first `addu`; a conversion on the base gives base-first): in a three-term pointer sum whose base is a cast pointer, the written order decides. In faultDrawGlyph, `dst = xoff + (u16 *)gFaultFramebuffer + yoff` (xoff = `(gFaultCursorX + 3) * gHiResScale * 4`, yoff the row term) is the only order that matches; four alternative orders fail. The target's offset-first `addu` proves the source order, and the spelling is ordinary C (lead ruling, untagged).
