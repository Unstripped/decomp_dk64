When one value is both an argument and an operand of another argument's expression, uopt coalesces the shared CSE temp into the argument register (`$a0`), even for a named local wherever it is declared or scoped. Only a pointer<->integer conversion (`(s32)`/`(u32)`) on the argument use creates a separate ucvt node, so the temp stays in `$v0` and the target's `move a0,v0` appears; pointer-to-pointer casts do not. (Inverse of Q0902.)

Evidence: mapChunksApplyLights (global/55B20.c): 0x4be4/0x4c0c/0x4c14 vs the plain form; a u32-field diagnostic moves the same pattern into mapChunkFreeIdleBuffers (0x4d58/0x4d68). The site stays tagged.
