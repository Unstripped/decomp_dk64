In `eepromCopySlot` (src/global/104F0.c, 2026-11-15 cleanup), the dead test kept from 8fa679 to 6c4c65 and respelled `if (version) {}` adds block units only to `version`, `i` and `j`. It does nothing to `found`. Priorities moved from version 42 to 35 and i 41 to 38.27, while found stayed at 36.67. Any int local worked as the test operand. An inner `if (j == i || valid[j] == 0) continue;` put `i` back in its old colouring order, but `found` still did not rank above `version`. This shows that the extra blocks only raise the divisor for webs whose live range covers the new blocks (see Q0523's `livebbs` divisor). You can't use them to lower a web that is not live across the site. A 900 s permuter run went from 170 to 10, and it got there only by adding another dead test. That matches the step-by-step lever in Q0722.
