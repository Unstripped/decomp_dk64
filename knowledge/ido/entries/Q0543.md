uopt takes the cheapest legal register (`cupcosts`: call-adjacent ranges pay per caller-saved register, callee-saved ones pay a first-use cost) and the lowest number only on ties, so for call-free ranges read the variable's `forbidden:` line (`uopt_trace.sh -l 5`) and find which earlier candidate live in one of its blocks (a call's argument registers, a local shared with another loop, a spilled call-argument expression) supplies each register the target forbids; guide `ido-load-overlay-diagnostics` first (`python3 tools/quirks.py get ido-load-overlay-diagnostics`). If single-local reuse stalls, test coordinated lifetime partitions across loops rather than rejecting each reuse in isolation.
