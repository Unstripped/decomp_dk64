In `lightCheckPlayerDistance` (5E2F0), a file-local byte-offset view `((T *)((u8 *)base + i * sizeof(T)))->field` of the shared `gPlayerSlots` array was replaceable by `gPlayerSlots[i].field` written at every use, with no pointer temp (`PlayerStruct *`, stride 0x2F0; camX/Y/Z read in x, y, z order). fdiff OK; the permuter suggested it (output-0-1). Unlike Q0606, indexing the shared struct here does not swap `addu` operands, so try it before keeping a stride view.
