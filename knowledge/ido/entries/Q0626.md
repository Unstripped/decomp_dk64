`tools/fdiff.sh <copy> <src> FUNC` can print CURRENT (0) with no diff lines when a long function's first difference lies beyond the asm-differ output window (`sfxUpdateLevelAmbient` differs at 0x2108; `bossMainStep`). Trust the exit code or an objdump diff of the two objects, not the absence of diff lines.
