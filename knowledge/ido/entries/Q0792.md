If a callee takes the same address twice, once as a pointer and once as an s32, the CSE'd sum is computed into the argument register of whichever argument is the plain (unconverted) expression; the other gets a copy. `(s32)base + off` for the integer argument with `(T *)((s32)base + off)` for the pointer puts the sum in the integer argument's register.

Evidence: mapHeaderLoad (global/2F550.c, a01a33 fixed).
