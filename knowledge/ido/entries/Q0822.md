String literals are placed in .rodata in order of appearance; a function-local `static const` array is emitted after that function's literals, a file-scope one before them (Q0394). The declaration scope of a const table therefore follows from its .rodata position relative to the strings. Also, under `-signed` a `char *` read emits `lb` even when cast or assigned straight to a u8: only the pointee type decides lb vs lbu.

Evidence: global/90D80.c and jetpac/0.c (fdiff 1 with the wrong scope; global/C0EE0.c matches only because its labels come first), merge 90ce8276.
