Goto-built loops `L: body; if (c) goto L;` = `for (;;) { body; if (!c) break; }` (viModeApplyHighRes, mapFindSlotIndex). `while(..){ if(c) goto next; ... next: i++; }` = `for (; cond; i++)` with continue, init outside the for (meshApplyAnimation). Gotos to duplicate `return K;` labels = a switch with cases in body order (actorGetPlayerThreshold). IDO 7.1 -g `goto a; a: f(); goto b; b: return 0;` = `switch (x) { default: f(); break; } return 0;` (alSaveParam). Gotos jumping into a shared tail (backward into another case, or several arms to one tail) are usually original source: IDO never tail-merges, so duplicated tails add code and fallthrough variants re-colour (bossScriptStep block_16, camComputeEyeFocus, playerUpdateCommon case1/case2 where switch adds a +8 switch temp).
