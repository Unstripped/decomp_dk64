55B20 mapChunkEmitLayerDisplayLists: naming the parameter `gfx` and nesting the cell work under `if (dl[layer] != -1)` gives the
gfx web (15.11) priority over the gSPSegment/gSPDisplayList `_g` temps (15.0, s1/s2), so `if (p == 0) {}` and
`gfx = (Gfx *)((u32)gfx | 0)` became unnecessary. With both `==` operands written as array reads the source order decides the `bnel`
register order; with a pointer local on one side both orders give `bnel a0,t2`.
