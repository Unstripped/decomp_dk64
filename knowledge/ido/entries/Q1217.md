Supersedes the "extended block" wording of Q0820/Q1061. A field reload is removed when the load is available at the start of the reload's basic block and no store inside the block kills it. Availability at block start is global and ANY store through the same pointer kills it (f32 included); the in-block check is type-based (an f32 store through the same pointer does not kill an s32 field load, an s32 store does). Evidence (jetpac/1A60 jetpacUpdatePlayerMovement): `goto L; L:` before the four reloads (0x9c4/0x9e0/0xac8/0xaf8) gives 0, an unreferenced label 4, a read in one flying arm 2, in both 4.
