a narrow (`char`) callee return gives the caller's web a byte home that can shift ~6 other homes; a web whose live range crosses a call in linear order gets a memory home even in caller-saved registers. In `resParseVariant` (112080), the code matches only when the text branch's record cursor is the same `u8 *p` variable the grid branch uses as its cell cursor. Any separate `ResRecord *` cursor lets `item` take s1 and drops its a3 spill to the 0x28(sp) home (.text 5472 vs 5488).
