In transformBarrelUpdate (80150), the sound call guarded by `sound != 0 && !(gGlobalCutsceneFlags & 2) && gCurrentMap != 3 && ... != 0xD1` needed a dead global read (`if (gPlayerCharacterId) {}`, FAKE 2ba6be). Written as `switch (gCurrentMap) { case 3: case 0x11: case 0x52: case 0xD1: break; default: sfxAllocateChannel(sound, 1.0f); }` it matches: the target compares the four maps in order (`li at,K; beq v0,at,skip` at 0x3f64-0x3f80) and then reloads the sound local from its stack home (`lh a0,98(sp)` at 0x3f84), which the plain `&&` form keeps in a temp; the switch temp (Q0296) is what gives that home. Removing that one steer made two older dead ifs in the same function unnecessary (4925be, 516e63). Check that every case value is compared in the target before accepting such a switch; see the boundary in Q0845.
