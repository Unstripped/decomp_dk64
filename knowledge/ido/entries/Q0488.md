Levers that flipped it: a copy local used only in the compare (`iy = (s32)y; if (iy == arg)`), `(ret ^ 0) == field` with the wrapped call-result side on the left, `a - (0 - b)` for an `s16 + u16[]` sum, struct-field vs raw `*(T *)(base + off)` read (no CSE between them), `s[i].f` vs `(s + i)->f`, `&((T *)&base[i])->f` (keeps `addu` as base+idx) vs `((T *)base)[i].f` (swaps the operands; `camUpdatePlayerYaw`), `x != (*st).f` vs `x != st->f` (different `beq` operand order; `csCmdModelStepAnimation` and `csCmdStepSequenceProgress` keep the `(*st).` spelling), the constant first with no casts in a multi-term OR, every order of `base + const + idx*K`.
