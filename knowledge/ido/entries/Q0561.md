From `lightSampleColorAtPosition` (leftovers revisit 13, parked stage 6, full 7): (1) cfe puts a `loc` record between a dead guard's `fjp` and its label, so `uoptinput.c`'s empty-if removal never fires; the guard takes part in copy propagation, CSE live ranges and liveness, and only ugen's labelopt deletes it, without code. `if ((nx * p->f) + (ny * p->f) + dz) {}` in a later block keeps nx/ny's stores and home slots with no load (no_nested_ops blocks their propagation, Q0559). (2) Frame = align8(saved registers) + 16 + align8(Mmt length) + temps, and Mmt length is the highest offset of any local uopt still references (`highestmdef`, dead-guard references included): unused locals declared above the lowest referenced local take slots, those below it do not (here one `s32 pad2;` after `i`). (3) A CSE's priority (refs x frequency over the bucketed unit count) can be set to an exact tie with propagated uses in a distant block: `if (nx + ny + nx + ny + nx + ny) {}` made the dx/dist and dy/dist temps exactly 15, so candidate order placed them after dist and before `(f32)arg3`. (4) A caller-saved range that holds the same candidate in the call block and the next block always gets its reload in that next block; a later reload in the target means the range was split, and a split piece starting with a reload loses movcost x frequency, so a split needs total saving <= the cheapest register cost (20 for caller-saved around one call in a loop). (5) `x / 3` in a loop can put 3 in a coloured register and emit `div` with the break 7/6 checks; no named `three` variable is needed.

Rewriting such a guard on an int local (`if (z) {}` → `if (z != 0) {}` / `if (!z) {}`) still matches but does not remove it: the cond flip is no fix for a dead guard (`playerStateEnterFallOnCheck`, `playerStateDamageFallTumble`).
