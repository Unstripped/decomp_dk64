Levers found in leftovers revisit 7 (2026-11-03), each tagged with the task that found it; they matched 13 functions that had stalled for 4-7 attempts.[^roadmap] Read together with IDO quirks and uopt statics and live ranges (guide ido-uopt-statics-and-live-ranges: python3 tools/quirks.py get ido-uopt-statics-and-live-ranges). uopt source for checking colouring rules: n64decomp/ido `src/uopt/uoptreg2.c`, `uoptcopy.c`.

- (Ctrl) KEY: a named local holding only a formal's modified value (`s16 index = arg1 - flag;`) colours before later temps; updating the narrow formal IN PLACE (`arg1 -= flag;`) removed that ghost and matched func_80613AF8/func_80613BA0 with zero FAKEs (3 FAKEs + score 3 before). Try it before any dead-test search.

- (MenuA) Target tail spill (`sw sN,home(sp)` at a join, `lw v0,home(sp)` at return) without volatile: a separate returned local `ret = arg1;` plus a dead redefinition `arg1 = 0; // FAKE` after arg1's last use makes ret conflict with arg1; with s-regs full it stays uncoloured (`not colored (-ve save)`) and spills at def.
- (MenuA) `as1probe.py keep` also writes `DIR/t.s` (ugen asm with virtual temps, `.loc`, `.alias`): shows whether a PRE reload sits before/after a store; a dead test's `.loc` owns the reload it triggers. uopt adjsave ~5.0 per use per loop iteration: predict s-reg order in simple loops by counting references. Constant-trip `for (i=1;i<5;i++)` loops get unrolled/peeled; pointer `do {} while (p < end)` stays a loop.
- (Bsp) Statement order of a spilled variable's DEFINITION picks which candidate holes land in which spill slots, even though uopt sinks the computation to its use (frustumCalculateCornerRays matched by moving `sp54 = sp58 * arg1;` up). Try before dead tests/pads.
- (Bsp) FP colouring priority follows adjsave (extra references), while as1 emits loads in source order: write loads in the target's order, then give the vars to colour first extra dead references AFTER their last use (no uninitialised read). Float-constant web count (one shared vs several single-use literal spellings) shifts the ugen FP ring phase across the whole function.
- (Eep) KEY: a long arithmetic chain spelled as a series of statements on ONE s32 local (`x = G; x += c; x = (x & M) + k; x &= M2; x /= 8; size = x;`) reproduces ring temps and keeps the result in the local's colour; the single-expression form misplaces the first load (eepromCopySlot matched; plus a no-code `x = x | 0; // FAKE` after last use).
- (Eep) `== (call(...) ^ 0)` around a call result flips beq/beql operand order (Patrol lever) in eepromValidateSaveSlots too. A prototype `void f(u8, s32)` before a K&R `unsigned char` definition gives `andi a0,sX,0xff` per call, but a later `extern void f();` then fails (block-scope externs are file-scope).
- (Player) KEY: uopt copy-propagation does NOT forward a single-use local whose expression contains an indirect load (ilod): such a local stays a real var candidate (own colour/home). Address-taken scalar locals (`&a`, `&b` to a callee) are plain isvars and get forwarded (local vanishes); the SAME values as a constant-indexed ARRAY local (`f32 X[2]`, pass `&X[0]`,`&X[1]`, read `X[0]+X[1]`) are ilods, so `mid = (X[0]+X[1])/2` stays a candidate (playerHeldActorFollowStep matched, 0 FAKEs). Symptom: target colours/spills a temp that natural C folds away. uopt source: github.com/n64decomp/ido src/uopt/uoptcopy.c, uoptreg2.c (adjsave = totalsave / bucket(n_liveunits + n_reachingbbs), ties by candidate bit order).
- (Text) uopt colours constrained candidates first by adjsave, the rest in candidate-index order: a candidate hoisted early (statement order) takes t2-t5 first, pushing later ones to s-regs (textBlitGlyph s0-s3 fixed by ordering phase,w2 before dstRow). With t2-t5 all coloured, ugen's ring has only t6-t9 and falls back to v0 (`andi v0; sltu t7; move v0,t7` idiom). First-declared narrow local gets the highest home; consecutive u8 locals pack into one word. Each block-scoped `Gfx *_g` takes its own home word.
- (Cs) KEY: a copy `q = p` is copy-propagated away at a join unless its reaching defs differ: plain `q = p;` in one arm and `q = (T *)((u32)p | 0); // FAKE` in the other keeps q a real second web (target `lw v1; move a0,v1` / `lw a0; move v1,a0` pairs; func_8064AC28 matched). Define q inside the arms AFTER the call (a copy before the call makes q callee-saved). Hand-peeling the first loop iteration places the copy after the peeled store. A one-statement loop body on the `for` line changes unrolling/schedule (LAYOUT). uopt `spilltemps` gives temp slots to uncoloured items in candidate-bit order.
- (Coll) KEY: dead-store kill: a dead store to an OPERAND of a just-assigned var (`nz = dx*dy...; dy01 = 0.0; // FAKE`) stops uopt forwarding nz's expression into the next statement of the same block, so the var and the expression candidate stop interfering (collisionTestActorBoxFloor 32->21, func_80668E9C 38->17). uoptcopy.c refuses to forward expressions with >=10 variable leaves. ugen FP temp phase in a block cycles ascending rotations of {f6,f8,f10} under no-code changes; a descending order needs real code.
- (Map55) Spill-slot rule: the topmost uopt temp slot lands 16 bytes below the LOWEST declared vreg word; locals declared after an array sit below it. To move spill temps up, declare nothing below the array (reuse a pad word as loop counter, replace a pointer local by a #define) (mapScreenRectBuildFrustum matched).
- (Map55) `(s32)SYM + idx*4` yields a ucvt(lda) expression candidate (hoisted); `&((T **)SYM)[idx]` yields a plain address-constant web emitted with other hoisted constants in DESCENDING register order, so as1 fills a guard `blez` delay slot with the first `li`. If an earlier loop uses the same symbol, the webs merge and the constant goes to the prologue (mapNodeAssetParse: earlier loop spelled off the neighbour symbol, FAKE-tagged).
- (Map55) uoptreg2.c: in a LEAF a candidate is constrained iff it interferes with >=22 live ranges (non-leaf: always); constrained ones colour first by adjsave (first-fit lowest reg), unconstrained last in bit order; hoisted rlods are emitted descending. `x*9*4` and `x*36` both fold to `mpy x,36`.
- (Model) Home offsets first: sp offsets of spilled vars expose declaration order (every declared scalar gets a home top-down in declaration order with natural alignment, register-resident ones too: `s32`/pointers take a word, `s16`/`s8` pack at 2/1 bytes, as retyping two `s16` locals to `s32` grew `enemyGridStateStep`'s frame by 8; uopt temps below the lowest home). Count homes from the target and order declarations / insert `s32 pad` words to match BEFORE any colouring search (modelSlotResolveAssetTextures 54->43 from this alone). uoptreg2.c: first use of an s-reg costs firstUseCost = movcost*0.25*curstaticno clamped [4,60]; cupcosts penalises a reg differing from a live unit's hinted arg reg, so a var reused as a call-arg pointer copy gets a0 (use a separate pad var for the copy).
- (MiscA) KEY ugen parm hint: a single-chain call-arg tree (`f(g->c * 4 + 4)`) puts the last load before the arithmetic in a0; a binary-shaped tree puts its leaves in ring temps. as1 deletes `andi x,0xFFFF` after `lhu`, so `((u16)x & 0xFFFF)` gives a ring leaf with no extra code (but lhu, not lh). Fixing that ring phase made 3 old dead-test FAKEs removable (camInitZones 25->1): re-test FAKEs after any structural fix.
- (MiscA) Assign-in-condition hidden local: `if ((v = S[i*2+1]) != S[(i-1)*2+1]) { G[k].unk0 = v; }` fixed a v0/a0 colouring swap no dead test could. A hidden local for a constant address (`end = (u32 *)func; while (p < end)`) gives `lui a3; addiu a0,a3,lo` vs inline `lui a0; addiu a0,a0`.
- (MenuB) KEY: a mask var later REDEFINED (`lim = mask; i = lim; ... lim = 5`) keeps `i` a copy only by accident; give the cap its own var, compute `i = E` directly and re-spell E at each test: uopt CSEs E into v0, i stays the s-reg copy (menuHandleControllerSlotInput matched, 0 FAKEs).
- (MenuB) `.5f`, `0.50f`, `5e-1f` are distinct literal webs from `0.5f`: an f32 ARG literal spelled differently from a `* 0.5f` multiply gets its own `lui aN,0x3f00` instead of `mfc1 aN,$f2`. A count that looks exact can hide compensating errors: compare per-opcode counts with expected.
- (MiscB) No-code term `+ ((s32)X * 0)` appended to a statement that consumes an isop candidate adds one uopt reference (+1.0 adjsave) WITHOUT splitting blocks: fixes colour order among tied isop candidates (ties break by candidate number), e.g. a 3-way a0/a1/a3 rotation (func_80709890 matched). Self-stores, `(void)x`, `x*0;` statements add nothing. `idx = (dir = x)` vs `dir = (idx = x)` picks which var gets the load's dest vs the copy. Wrapping a switch in `do {} while (0)` removes as1's entry-stall `lui` hoist from the default label (but may turn a coloured var into a ring web).
- (Ovl) ugen t-ring is LRU over free scratch regs (by last-use time; never-used regs oldest: t6,t7,t8,t9,t1..t5, unhinted may take v0,v1,a0..). When target temps skip fresh regs for old ones, the original burned N temps earlier in that statement: add no-code narrowing wrappers, e.g. `x = (s16)(s32)(f64expr) - 0x400;` vs `(s16)((s32)(..) - 0x400)` (bossFollowerActorUpdate text 77->40). Grid wrapper chains {s16,u16,s32,u32}^0..3 at inner/outer RHS positions, score count-exact.
- (MiscC) KEY: single-user globals as FUNCTION-LOCAL STATICS (needs a .data/.bss carve so the object sits in the TU): func_806E3E40 with static D_807FD6E0/E1 is count-exact natural C (text 16 vs 53 as externs); schedDlDebugDump with static D_80746A14..2C drops text 177->140 with no FAKEs. - (L878) Inline field reads (`st->unkC` at each use) vs a named local `a = st->unkC` flip commutative `mul.s`/`add.s` operand order (CSE candidate vs var): put inline-field read sites in the annealing pool next to named locals. - (Arcade) Size-mismatched memory residency: a local accessed at two sizes (`u16 S[2]; *(u8 *)S = x; ... = *(u8 *)S;` + dead `if (S[0]) {}`) stays in memory and its narrow read is a real ilod that PRE hoists into a loop preheader. `i = 0; do { ...; i++; } while (i < 3);` with i++ last puts the pointer increment in the bne delay slot (a `for` header puts the store there). - (L1169) uopt spilltemps gives a temp slot to EVERY code-motion candidate (coloured or not) in ascending bit order from the top, reusing a slot only for disjoint regions: a coloured never-spilled candidate leaves a hole slot. Dead tests on forward-substituted scalar locals emit nothing; only memory-resident elements respond. `a ^= 0; a = (s16)a;` between calls kills a CSE of `(s16)a`.
- (L1221) A dead `if` at the top of a loop body (or joined onto the `for` line) leaves the loop's hoisted constant unhoisted, so it stays a ring `li` like the target: fixed the t-ring phase of every later arm (vsprintf 80->6). - (Carve7) Function-local statics are emitted in .data at the function's source position (between surrounding file-scope definitions); a static needs explicit `= 0` to land in .data not .bss. - (L1159) Double/float literal spellings are NOT fully canonicalised: `255.0` vs `255.` vs `255.00`, `0.10f` vs `0.150f` split constant webs per site; integer literals in float contexts (`dist == 0`, `x = 1`) are separate webs too (annealed per-site spelling: lightApplyToActors 360->296). - (W3Near) Truthiness vs `!= 0` head on a static byte decremented in an arm (`if (E) { E -= 1; }` vs `if (E != 0)`) flips the reload cvt candidate's colour (v1 vs v0): func_806E3E40 matched FAKE-free.
